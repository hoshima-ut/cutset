# Contributing to Cutset

Start with the [Cutset handbook](development/README.md), install the [local secret checks](security/credentials.md), then select an acceptance case from the [task board](development/progress.md). Use synthetic media when sharing a reproduction. Keep a change small enough for another person to repeat the same editing operation and check its result.

Run the local checks for the affected paths and record what actually ran. Document any editor listening test that still needs a person. GitHub Actions is disabled for this fork. Contributors and agents share the [engineering workflow](development/engineering.md) and the inherited [Rust and asset rules](../AGENTS.md). The [technical contributor guide](development/rust.md) explains how to change a command, effect, codec or panel.

Contributions to the code are licensed under MIT OR Apache-2.0. Preserve the applicable notices and third-party asset attributions. Use [docs/SECURITY.md](SECURITY.md) for security reports.
