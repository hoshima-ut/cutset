# CutsetをMacにインストールする

社内の配布担当から、署名・公証済みのDMG、バージョン、SHA-256を受け取ります。動画編集にはDMGだけで足ります。CLIのZIPはコマンドによる編集や自動化に使います。

1. Appleメニューの「このMacについて」でチップを確認します。Appleシリコン向けは `aarch64`、Intel向けは `x86_64`、両方に対応する版は `universal` です。ファイル名は `cutset-バージョン-macos-CPU.dmg` です。末尾が `-local.dmg` のファイルはビルドしたMacでの試用版です。
2. ターミナルで `shasum -a 256 ` と入力し、FinderからDMGをドラッグしてReturnを押します。表示された値が、配布担当から受け取った値と一致することを確認します。
3. DMGをダブルクリックし、`Cutset` を隣の「Applications」にドラッグします。コピー終了後にディスクを取り出し、「アプリケーション」から「Cutset」を開きます。開発元や公証についてmacOSに警告が出た場合は、ファイル名と表示された文言を配布担当に伝えてください。
4. 短い動画を読み込み、案件を自分のフォルダーに保存します。一度アプリを終了して案件を開き直し、再生できることを確認します。別のPCで続きを編集する場合は元の素材も一緒に渡します。[最初の案件と素材](project-and-media.md) ・ [タイムライン編集](timeline-editing.md)

## FilmCraftと一緒に使う

アプリは `/Applications/Cutset.app`、設定・復旧データの標準保存先は `~/Library/Application Support/Cutset/` です。FilmCraftの案件も同じ `.fcproj` 拡張子で開けます。最初は案件のコピーを使ってください。

Finderで案件を右クリックし、「このアプリケーションで開く」から「Cutset」を選びます。Cutsetは代替エディターとして登録されます。常に開くアプリを変更したい場合は、案件の「情報を見る」→「このアプリケーションで開く」で指定します。

## 更新・取り外し

更新前に案件と素材を保存し、Cutsetを終了して新しいDMGから `Cutset.app` をコピーします。取り外すときは終了して `Cutset.app` をゴミ箱へ移します。案件・素材・ユーザー設定は個別に管理します。

Windows・Linux・FreeBSDのインストーラーは上流版の識別子と導入先を使用します。Cutsetとしての社内配布は準備中です。開発者向けの生成手順、macOSの試用版と正式配布版の作り方は[ソースからのビルド](../development/build-installer.md)にあります。
