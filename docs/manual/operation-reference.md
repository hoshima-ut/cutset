# 目的別の操作一覧

色補正、タイトル、受け渡しなど、必要な操作から読める一覧です。デスクトップの項目名は日本語表示に合わせています。キーは既定設定の例です。割り当てを変更した場合はメニューから同じ操作を選べます。[初めての編集](README.md) ・ [仕様と検証の範囲](../verification/coverage.md)

## 編集画面を使いやすくする

| したいこと | デスクトップでの操作 |
| --- | --- |
| 編集用の画面配置に戻す | ［ウィンドウ］→［ワークスペース］→［編集］を選びます。その配置に加えた一時的な変更を戻すには、同じメニューの［保存したレイアウトにリセット］を選びます。自分の配置を別名で残すには［新規ワークスペースとして保存…］を選びます。[ワークスペース](../specs/workspace/README.md) |
| よく使う操作にキーを割り当てる | ［編集］→［キーボードショートカット…］で操作名を検索します。目的の行のキー欄をクリックし、新しいキーを押します。競合の表示と、アプリ全体・対象パネルのどちらに割り当てるかを確認して［OK］を押します。[ショートカットとパネル別の割り当て](../reference/filmcraft/keyboard.md) ・ [メニューと文脈操作](../specs/commands/README.md) |
| 素材に合わせたシーケンスを作る | ［プロジェクト］パネルで読み込み済みのクリップを右クリックし、［クリップから新規シーケンス］を選びます。シーケンスのタブと、タイムラインに配置された素材を確認します。[素材と案件の操作](project-and-media.md) |

## 編集点、効果、色を調整する

| したいこと | デスクトップでの操作 |
| --- | --- |
| 見直す位置に印を付ける | タイムラインの目盛りをクリックして再生ヘッドを合わせ、［マーカー］→［マーカーを追加］（`M`）を選びます。［前のマーカーへ移動］と［次のマーカーへ移動］で印の位置を辿れます。素材自体に印を付ける場合はソースモニター側のマーカーボタンを使います。[タイムラインのマーカー](../specs/editing/ED-55/requirements.md) ・ [マーカーと取り消しの確認例](../verification/marker-history.md) |
| クリップの先頭をフェードインさせる | ［ウィンドウ］→［エフェクト］で［ビデオトランジション］→［ディゾルブ］→［クロスディゾルブ］を開きます。映像クリップの左端にドラッグし、開始側だけが強調されたら離します。追加したトランジションをダブルクリックして長さを調整します。直前の映像と端が接している場合は、2つの映像をつなぐ効果になります。[フェードの手順と仕上がり](../reference/filmcraft/getting-started-fades.md) ・ [エフェクト](../specs/effects/README.md) |
| 時間とともに不透明度を変える | タイムラインで映像クリップを選び、［ウィンドウ］→［エフェクトコントロール］で［不透明度］を展開します。変化の開始位置に再生ヘッドを置き、値の横のストップウォッチをオンにします。開始の値を設定したら、再生ヘッドを別の位置に動かして次の値を設定します。2点の間を再生して変化を確かめます。[キーフレームの操作部](../../crates/ui-egui/src/panels/effect_controls.rs) |
| 明るさを補正して結果を比較する | 映像クリップを選び、［ウィンドウ］→［カラーグレーディング］を開きます。初回は［クリップにカラーグレーディングを追加］を押します。［基本補正］の［露出］を動かし、パネル上部の `fx` で補正のオン・オフを比較します。信号レベルを見るには［ウィンドウ］→［ビデオスコープ］を開きます。[カラーの仕様](../specs/color/README.md) ・ [補正パネルの項目](../../crates/ui-egui/src/panels/lumetri.rs) |

## タイトル、字幕、音声を仕上げる

| したいこと | デスクトップでの操作 |
| --- | --- |
| 映像の上にタイトルを載せる | シーケンスを開き、タイトルを置く位置に再生ヘッドを合わせます。［文字ツール］（`T`）で［プログラム］モニターの配置位置をクリックして入力します。段落を枠の幅で折り返す場合は、文字ツールで枠をドラッグしてから入力します。作成した文字はグラフィッククリップのテキストレイヤーに保存されます。[テキストレイヤーと段落](../reference/filmcraft/graphics.md) ・ [グラフィック](../specs/graphics/README.md) |
| 字幕を別ファイルで渡す | ［シーケンス］→［キャプション］から追加し、字幕の本文と表示区間を設定します。書き出し時にサイドカーを選ぶと、動画と別にSRTまたはWebVTTを渡せます。受け取り側のプレーヤーで字幕ファイルを読み込み、冒頭と末尾の時刻を確認します。[字幕の入力と書き出し](audio-captions-export.md) ・ [字幕の納品](../specs/captions/CC-04/requirements.md) |
| 音量を徐々に変える | 音声トラック見出しの菱形から［クリップのキーフレーム］を選びます。クリップの音量線に［ペンツール］（`P`）で開始点と終了点を打ち、［選択ツール］（`V`）で終了点を下にドラッグします。その位置に向けて音が小さくなります。クリップ全体を一定量上げ下げする場合は［クリップ］→［オーディオオプション］→［オーディオゲイン…］を使います。[音量線とキーフレーム](../reference/filmcraft/getting-started-fades.md) ・ [音声の仕様](../specs/audio/README.md) |

## 別の編集者・別のツールへ渡す

1. 渡すシーケンスのタブを選択し、作業中の案件を保存します。［ファイル］→［書き出し］→［OpenTimelineIO…］から保存先を選び、タイムラインの交換ファイル（`.otio`）を書き出します。[素材管理と納品](../specs/media-delivery/IO-52/requirements.md)
2. `.otio` と参照先の素材を一緒に渡します。相手の編集ソフトで読み込んだら、シーケンスの長さ、代表的なカットのフレーム、素材の参照先を照合します。たとえばグラフィック素材は、この変換では欠落参照として記録されます。タイトルの見た目も渡す場合は、参照用の完成動画を添えて確認します。[形式ごとの変換範囲](../../crates/interchange/README.md) ・ [受け渡しの設計](../specs/workflow/UX-09/requirements.md)

## ブラウザ版とAI連携

| 利用場面 | 現在の扱い |
| --- | --- |
| ブラウザで素材を開いて保存する | Web版を起動したページに素材をドロップするか、ファイル選択から開きます。単独で開いたWeb版では、保存した案件や書き出したファイルはブラウザのダウンロード先で確認します。ブラウザ内の自動復旧領域と、手元に保管する案件ファイルは別です。プロキシ作成やマスク追跡などはデスクトップ側で行います。[ブラウザ版の操作と制限](../reference/filmcraft/web.md) ・ [ブラウザ仕様](../specs/browser/README.md) |
| AIで編集案を作り、画面で試聴・採用する | Cutsetの編集提案画面と外部モデル接続は計画段階です。既存のMCPは編集命令を外部ツールから呼ぶための入口です。開発用CLIでは固定した候補の試聴範囲を計算できます。モデルの接続、APIキーの扱い、採用前のプレビューについては設計書に記載しています。[モデル接続](../architecture/model-connections.md) ・ [AIと拡張](../specs/ai-plugin/README.md) ・ [試聴計画の実行記録](../development/progress.md) |
