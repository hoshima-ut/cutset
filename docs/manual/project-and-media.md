# プロジェクトを作り、素材を読み込む

音声の入った短い動画を1本使います。練習には手元のH.264のMP4が適しています。作業用フォルダーに動画を置き、編集が終わるまで同じ場所に保管してください。プロジェクトファイル（`.fcproj`）には編集内容と素材の参照先が保存されます。素材そのものは元のファイルから読みます。[プロジェクトファイルの形式](../reference/filmcraft/project-files.md)

## 空のプロジェクトから始める

1. 今開いているプロジェクトに残したい編集があれば、先に［ファイル］→［保存］を選びます。
2. ［ファイル］→［新規］→［プロジェクト…］を選びます。続けて［ファイル］→［別名で保存…］を選び、作業用フォルダーに `practice.fcproj` として保存します。
3. ［ファイル］→［読み込み…］で動画を選びます。［プロジェクト］パネルに素材名が表示されます。ここには、この後シーケンスに配置できる素材が並びます。
4. ［ファイル］→［新規］→［シーケンス…］を選びます。シーケンスは、映像と音声を時間順に並べる編集単位です。名前に「練習」を入力して［OK］を選びます。タイムラインに新しいシーケンスのタブが開きます。
5. ［ファイル］→［保存］を選びます。ここまでで、プロジェクトに素材1本と空のシーケンスができました。

手元に動画がなければ、［ファイル］→［新規］→［デモプロジェクト］でも操作を試せます。［別名で保存…］で練習用のファイルを作り、［プロジェクト］パネルで `Footage` ビンを開くと素材を選べます。`Main Edit` にはすでに編集が入っています。上の手順4・5で空の「練習」シーケンスを作って保存すると、次の章を同じ状態から始められます。

## 素材が見つからないとき

| 状況 | 確認すること |
| --- | --- |
| 読み込んだのにタイムラインが空 | ［プロジェクト］パネルに素材名があるか確認します。タイムラインへの配置は次の章の［挿入］で行います。 |
| 編集途中で素材を移し、開き直すとオフラインになる | ［ファイル］→［メディアをリンク…］で不足している素材を選び、移動先の元ファイルを指定します。つながった映像と音を確認して保存します。 |
| 動画を読み込めない | 画面のステータスに出たエラーと元ファイルのコーデックを確認します。たとえばProRes RAWやBRAWは対応表でデコード未対応です。撮影元のツールで視聴用のH.264などに変換したコピーを使えます。[形式別の対応状況](../reference/filmcraft/codec-parity.md) |

次は、読み込んだ素材から使う部分を選びます。[素材を切り出してタイムラインを編集する](timeline-editing.md)
