# Cutset 操作マニュアル

操作名は日本語表示に合わせています。英語で起動した場合は、設定の ［General］→［Interface Language］で日本語を選べます。

初めての方は、短い動画を一本用意して次の順に進めてください。案件ファイル（`.fcproj`）、元の素材、書き出した動画は別々に保存します。

| 順番 | 操作 | 終わったときの確認 |
| --- | --- | --- |
| 1 | [インストールして起動する](install.md) | 編集画面を開ける。 |
| 2 | [案件を作って素材を読み込む](project-and-media.md) | 素材がプロジェクトパネルに表示される。 |
| 3 | [タイムラインで編集する](timeline-editing.md) | 使う区間を決め、編集を取り消し、保存した案件を開き直せる。 |
| 4 | [音声・字幕を確認して書き出す](audio-captions-export.md) | 出力ファイルを開き、映像・音声と指定した範囲を確認できる。 |

マーカーや色調整、タイトル、他の編集ソフトとの受け渡しを調べるときは[目的別の操作一覧](operation-reference.md)を使います。

社内で配布物を作る担当者は[ソースからインストーラを作る手順](../development/build-installer.md)を参照してください。開発中のAI機能や他ソフトとの互換性は、機能別に[製品仕様](../specs/index.md)と[検証範囲](../verification/coverage.md)で確認できます。
