# 素材を切り出してタイムラインを編集する

前章で開いた「練習」シーケンスに、素材の数秒間を配置します。［ソース］モニターは元の素材を確認する画面、［プログラム］モニターはタイムライン上の編集結果を確認する画面です。それぞれに別の再生ヘッドがあります。[プロジェクトと素材の準備](project-and-media.md)

## 使う範囲を選ぶ

1. ［プロジェクト］パネルで動画をダブルクリックします。［ソース］モニターに映像が表示されます。
2. ［ソース］をクリックし、スペースキーで再生・一時停止します。使いたい最初のフレームで止め、モニター下の［イン点をマーク (I)］を押します。既定のキーは `I` です。
3. 数秒先の最後に使いたいフレームへ移動し、［アウト点をマーク (O)］を押します。既定のキーは `O` です。アウト点のフレームも使用範囲に含まれます。

## シーケンスに挿入する

1. タイムライン上部の時間目盛りをクリックし、配置したい位置に再生ヘッドを置きます。練習ではシーケンスの先頭を選びます。
2. ［ソース］モニター下の［挿入 (,)］ボタンを押します。初めて置く素材の設定が違うと確認画面が出ます。動画のサイズやフレームレートで編集する場合は［シーケンス設定を変更］、先に決めた納品設定を使う場合は［現在の設定を維持］を選びます。
3. タイムラインにクリップが現れます。映像と音声のある素材では、挿入先の映像・音声トラックにそれぞれ配置されます。クリップ上に再生ヘッドを移動し、［プログラム］で再生して始まりと終わりを確認します。

既存の編集に［挿入］を使うと、挿入の影響を受ける後続クリップが後ろへ動きます。同じ位置を別の映像で置き換える操作は［上書き (.)］です。どちらを使うか迷ったら、編集前後で後続クリップの開始位置を見比べてください。

## 終わりを短くし、元に戻す

1. タイムラインをクリックし、`V` で［選択ツール］にします。クリップの右端を左へ少しドラッグして離します。末尾が短くなります。中央をドラッグすると、クリップ全体を移動します。
2. ［編集］→［取り消し］を選びます。右端が元の位置に戻ります。［編集］→［やり直し］で、短くした状態になります。
3. ［ファイル］→［保存］を選びます。［ファイル］→［プロジェクトを開く…］から `practice.fcproj` を開き直し、タイムラインのクリップ長と再生結果を確認します。

| 状況 | 確認すること |
| --- | --- |
| `I` や `O` が別の場所に付いた | ［ソース］の再生ヘッドを動かしたか確認し、モニター下のイン点・アウト点ボタンで設定し直します。 |
| ［挿入］を押しても配置されない | ソース素材と編集先のシーケンスが開いているか、目的のトラックがロックされていないか、挿入先の映像・音声が有効かを確認します。 |
| 配置後の映像が見えない | 再生ヘッドがタイムライン上のクリップに重なっているか、［プログラム］モニターを見ているかを確認します。 |

次は音量を調整し、字幕付きの動画を書き出します。[音量・字幕・書き出し](audio-captions-export.md)

挿入・上書きの設計、モニターの詳しい操作は個別の資料にあります。[挿入と上書きの仕様](../specs/editing/ED-15/requirements.md) ・ [モニターの操作](../reference/filmcraft/monitors.md)
