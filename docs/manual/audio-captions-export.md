# 音量を調整し、字幕付きの動画を書き出す

編集したシーケンスを使って、クリップの音量を下げ、字幕を1件入れたMP4を作ります。始める前にタイムライン上のクリップを再生し、元の音量を確かめておきます。[タイムライン編集](timeline-editing.md)

## クリップの音量を下げる

1. タイムラインの音声トラックで、調整する音声クリップをクリックします。
2. ［クリップ］→［オーディオオプション］→［オーディオゲイン…］を開きます。既定のキーは `G` です。
3. ［ゲインを調整］を選び、`-3` dBにして［OK］を押します。選択したクリップの現在のゲインから3 dB下がります。絶対値を指定するときは［ゲインを設定］を使います。
4. ［プログラム］で同じ部分を再生します。変化を比較する場合は［編集］→［取り消し］と［やり直し］を使います。

## 手入力の字幕を付ける

1. シーケンス上で字幕を出したい位置に再生ヘッドを置きます。［シーケンス］→［キャプション］→［再生ヘッドの位置にキャプションを追加］を選びます。字幕のトラックがなければ自動で作成されます。
2. 映像トラックの上に現れた字幕をダブルクリックします。［テキスト］パネルの［キャプション］で本文を入力し、欄の外をクリックして確定します。
3. タイムラインで字幕の左右端をドラッグして、表示する区間を調整します。その区間内に再生ヘッドを置き、［プログラム］に入力した文字が出ることを確認します。表示されないときは字幕トラックの目のアイコンを確認します。
4. ［ファイル］→［保存］で編集した字幕と音量を残します。

## MP4に書き出す

1. 編集したシーケンスを開いた状態で、［ファイル］→［書き出し］→［メディア…］を選びます。
2. ［ファイル名］に `practice-final`、［場所］に保存先のフォルダーを指定します。拡張子は形式に合わせて付くため、ファイル名には入力不要です。
3. ［形式］に［H.264］を選びます。［マルチプレクサー］で［MP4］、［範囲］で［ソース全体］を選ぶと、シーケンス全体が対象になります。音声も必要な場合は［オーディオ］の［オーディオを書き出す］を有効にします。
4. ［キャプション］→［書き出しオプション］で出力方法を決めます。［キャプションをビデオに焼き込み］は字幕を映像に固定します。再生時に表示を切り替える配布形式なら、［サイドカーファイルを作成］でSRTまたはWebVTTを選び、動画と字幕を一緒に渡します。
5. ［書き出し］を押して処理の完了を待ちます。指定したフォルダーの `practice-final.mp4` を別のプレーヤーで開き、最初と最後のフレーム、音量、字幕の文字と時刻を確認します。外部字幕にした場合は、プレーヤーで字幕ファイルも選びます。

| 状況 | 確認すること |
| --- | --- |
| 書き出した動画が極端に短い | ［範囲］を［ソース全体］に戻し、プレビューの開始と終了を確認します。 |
| 字幕がプレビューには出るのに動画に入っていない | 焼き込みが指定されているか確認します。サイドカー出力の場合は字幕が別ファイルに保存されます。 |
| 書き出した動画に音がない | シーケンスを再生して元の音が鳴るか、トラックがミュートになっていないか、書き出し画面で音声が有効かを確認します。 |
| H.265やAV1が選べない | 対応するハードウェアエンコーダーが必要です。動作確認にはH.264を選べます。 |

字幕の交換形式とトラックの扱いは[字幕の技術資料](../reference/filmcraft/captions.md)にあります。製品としての拡張予定や受け入れ条件は各機能仕様を参照してください。[クリップゲイン](../specs/audio/AU-04/requirements.md) ・ [字幕の手編集](../specs/captions/CC-02/requirements.md) ・ [字幕の納品](../specs/captions/CC-04/requirements.md)
