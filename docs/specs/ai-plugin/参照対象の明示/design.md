# 参照対象の明示の設計（AI-01）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

アシスタントを開くと選択配置・区間・案件全体のうち現在の読取範囲を示す。検索範囲と変更可能範囲を確認し、参照追加は編集者が選ぶ。

## データと処理境界

要求に案件版、許可された素材・配置IDと時間区間、読取・提案の権限を添える。サーバーへ送る文脈の組立時と候補取込時の両方で範囲を検証する。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M3](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/transcript.rs](../../../../crates/engine/src/transcript.rs)。

確認した関数：[targets](../../../../crates/engine/src/transcript.rs)。文字起こし対象の素材IDを明示指定・パネル選択から解決する。どちらも空のときシーケンスの音声へ対象を広げる既存動作がある。AIが外部送信する経路には、入力範囲をこれ以上広げない専用の検査を設ける。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
