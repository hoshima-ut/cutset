# 生成素材の来歴の設計（AI-08）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

生成候補のプレビューで元区間、生成区間、利用モデルを確認し、採用した版を通常の素材として登録する。後から生成区間だけを置換・削除できる。

## データと処理境界

生成済みバイト列を独立素材として識別し、選択版・元素材ID・入力範囲・モデル識別情報と関連付ける。再生・出力は保存済みの生成物を参照する。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M3](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/narration.rs](../../../../crates/engine/src/narration.rs)。

確認した関数：[write_and_import](../../../../crates/engine/src/narration.rs)。合成音声をWAVへ書き出して別の素材として登録する経路がある。生成映像とモデル識別情報・元区間・採用版の来歴保存は追加する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。

## クリップ端の生成延長

プラグインが対応する媒体、チャンネル数、継続時間を申告する。原本の参照区間と追加区間を別々に保持し、選択した映像・音声トラックだけを更新する。モデルが返した実際の尺を検証し、タイムラインへ適用する前に試聴できるようにする。

## タイムラインからの映像・効果音生成

生成延長とは別の要求として入力文、媒体、希望尺、挿入先、生成物の識別子と選択した候補を関連づける。進行中の要求と配置の確定を分け、応答の重複やキャンセル後の遅延応答ではクリップを増やさない。

<a id="premiere-27-3"></a>

## タイムラインの指定範囲に静止画を生成する（27.0との照合）

映像トラックに描いた範囲を候補の配置先として保持する。モデル、使用量の見込み、参照画像を提示し、採用した画像と配置を関連付ける。

<a id="premiere-27-4"></a>

## 音楽生成と映像に同期する効果音（27.0との照合）

音楽は尺と音声トラック、効果音は任意の映像同期点を指定する。試聴と確定を分け、利用条件は生成サービスが示す情報を記録する。

<a id="premiere-27-5"></a>

## 映像に合わせて環境音をレイヤー生成する（27.0との照合）

送信する映像範囲と生成先を表示する。環境音と単発音を時間位置付きの別配置として試聴し、採用するレイヤーを選ぶ。
