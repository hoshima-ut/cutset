# 生成素材の来歴の設計（AI-08）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

生成候補のプレビューで元区間、生成区間、利用モデルを確認し、採用した版を通常の素材として登録する。後から生成区間だけを置換・削除できる。

## データと処理境界

生成済みバイト列を独立素材として識別し、選択版・元素材ID・入力範囲・モデル識別情報と関連付ける。再生・出力は保存済みの生成物を参照する。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M3](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/narration.rs](../../../../crates/engine/src/narration.rs)。

確認した関数：[write_and_import](../../../../crates/engine/src/narration.rs)。合成音声をWAVへ書き出して別の素材として登録する経路がある。生成映像とモデル識別情報・元区間・採用版の来歴保存は追加する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
