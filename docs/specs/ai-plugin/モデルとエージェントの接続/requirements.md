# モデルとエージェントの接続の要件（AI-09）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

ローカル推論、利用者のAPIキー、契約が明示的に許す接続、エージェントホストを独立した能力として登録し、資格情報・権限・費用の責任範囲を表示する。

## 受入条件

同じ編集提案をローカル・BYOK・利用権を確認できる接続・外部エージェントの各アダプターからテストダブルで要求する。失効時は接続を要する能力だけを止め、秘密値は案件・ログ・プラグイン応答に残さず、意図しない課金先への切替を起こさない。

## 例外と復旧

契約の利用権がない、OAuthを取り消された、APIキーが失効した場合はその接続だけを停止する。送信済み範囲を示し、別の請求経路は編集者に選んでもらう。
