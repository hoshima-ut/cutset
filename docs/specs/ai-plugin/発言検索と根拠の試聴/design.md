# 発言検索と根拠の試聴の設計（AI-02）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

発言の候補を話者・引用・時刻付きで表示する。候補を選ぶと元の音声区間を再生し、文字の修正とタイムラインへの挿入を別操作にする。

## データと処理境界

検索結果に素材ID、発話ID、ソース時間、該当配置があればシーケンス時間を添える。発話の修正履歴と素材のメディア時刻を独立に扱う。

## 既存実装との対応

方針は「既存部品を拡張」。対象マイルストーンは[M3](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/transcript.rs](../../../../crates/engine/src/transcript.rs)。

確認した関数：[search](../../../../crates/engine/src/transcript.rs)。認識語列を検索し、各一致の単語インデックスと開始・終了時刻を返す。配置の素材時刻・話者との対応と試聴UIをこの結果に結び付ける。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
