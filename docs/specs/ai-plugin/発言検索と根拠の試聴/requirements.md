# 発言検索と根拠の試聴の要件（AI-02）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

話者、素材時刻、前後の音声を候補に添え、不確かな文字を編集者が照合できる。

## 受入条件

同音異義の固有名詞でも元の映像まで一手で戻れる。字幕文字の修正で映像を短縮しない。

## 例外と復旧

不確かな人名や発話時刻の欠落を候補上に表示する。元音声がオフラインなら試聴不能と示し、同名素材の音を代用しない。
