# 変更提案のプレビューの設計（AI-03）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

変更案を候補カードで開き、原音区間と短縮案を交互に試聴する。保護する区間を決め、採否を変えるたびに予想尺と影響範囲を更新する。

## データと処理境界

基準版の元位置と安定した配置IDから候補を表現する。採用分の累積移動量を計算し、原版の区間と提案後の対応表を返す。プレビューは履歴を作らない。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M3](../../../development/milestones.md)。

上流コードの照合先：[crates/edit/src/transcript.rs](../../../../crates/edit/src/transcript.rs)。

確認した関数：[find_pauses](../../../../crates/edit/src/transcript.rs)。語と語の間隔、残す時間、フレームレートから削除候補区間を算出する。個別に採否を保持するUIと原音との比較再生は別途実装する。

詳細は[個別の設計書](../../../architecture/edit-graph.md)を参照する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。

## 案件を参照して操作を提案するAI（27.0との照合）

案件への質問は参照した素材や配置を示して回答する。変更は対象ID、件数、差分を提示し、編集者の確定時に基準版と権限を再確認する。
