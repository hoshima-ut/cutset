# 変更提案のプレビューの要件（AI-03）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

基準版、配置ID、変更前後の範囲を持つ案を提示し、保護区間と個別調整を扱う。

## 受入条件

60秒版を試聴し、指定した一呼吸を保護し、個別の候補を手で直せる。

## 例外と復旧

重複候補や保護区間に交差する案は衝突位置を明示し、範囲を修正するまで採用しない。キャンセル時に再生位置と編集フォーカスを復元する。
