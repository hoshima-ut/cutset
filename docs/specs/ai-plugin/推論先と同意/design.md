# 推論先と同意の設計（AI-07）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

案件の推論設定で端末内・許可済み接続先を選ぶ。各要求の送信画面で字幕、静止画、音声等の種別と範囲を確認してから送信する。

## データと処理境界

接続先ごとの能力と案件ポリシーの共通部分だけを利用する。同意は接続先・送信内容・用途・範囲に紐づけ、素材参照を必要最小限へ絞る。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M3](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/transcript.rs](../../../../crates/engine/src/transcript.rs)。

確認した関数：[transcriber](../../../../crates/engine/src/transcript.rs)。注入済みの認識器かカタログにあるローカル音声モデルを選ぶ。端末内の文字起こしを再利用できる。クラウド送信の同意と案件ポリシーは新たな境界になる。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
