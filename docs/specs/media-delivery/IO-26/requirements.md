# IO-26 試聴と納品の素材選択 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

再生中の代理素材と書き出しに使う素材を独立指定する。

## 受入条件

異なる透かし付き原本・プロキシで2通りを書き出し、どちらの素材から作られたかを目視する。原本オフラインの場合も別に記録。

## 例外と復旧

原本指定の納品時に原本が欠落したら該当素材を示す。明示選択なしに代理で納品しない。

## 参照資料と確認項目

- [A183](https://helpx.adobe.com/premiere/desktop/organize-media/ingest-proxy-workflow/export-proxies.html)　書き出し時のプロキシ利用を明示して、識別用の印を入れた原本／プロキシのどちらが出力に採用されたか調べる。（公開手順）
