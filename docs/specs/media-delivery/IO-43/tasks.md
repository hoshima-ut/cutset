## 具体的な試験

左右で440 Hzと880 Hzを鳴らした信号をステレオで出す。音声単独版と映像付き版の両方で左右の周波数が一致する。

- QA-08　左右別パルスのステレオと多チャンネル素材を読み、元に合わせる設定と明示ダウンミックスで出力。 期待結果：受け手がファイルのチャンネル構成と実際に聞こえる信号を照合。対応外の構成では変更点が書き出し前に分かる。
