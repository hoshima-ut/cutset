# IO-43 音声と多重化 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

出力チャンネル、サンプルレート、単独音声または同一コンテナへの格納を選ぶ。

## 受入条件

左右別音、5.1ch、離散多チャンネルで、各チャンネルの位置と対応するダウンミックスを照合。映像のみ・音声のみも再生確認。

## 例外と復旧

容器に格納できないチャンネル数は代替形式を提示する。チャンネルを暗黙に間引いて成功扱いにしない。

## 参照資料と確認項目

- [A651](https://helpx.adobe.com/premiere/desktop/render-and-export/export-files/export-video-and-audio-files.html)　映像のみと音声のみを別々に保存し、独立プレイヤーで余分なストリームの有無を調べる。（公開手順）
