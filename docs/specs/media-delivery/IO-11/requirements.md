# IO-11 プレースホルダーと生成素材 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

後日差し替える仮素材またはテスト信号を長さ・種類を指定して作る。

## 受入条件

仮素材を同尺の実写に再リンク。黒と透明の上に載る下層の見え方、基準音の有無を確認。

## 例外と復旧

仮素材より短い原本を割り当てる場合は不足範囲を知らせ、選択なしに末尾を切り捨てない。
