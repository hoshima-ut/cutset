# IO-42 ビデオの符号化 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

映像出力の寸法・レート・コーデック・プロファイルを入力し、組合せを検証して符号化を開始する。

## データと処理境界

有理数のレートと表示寸法、ピクセル形式、ビットレート制御、アルファの要否をエンコーダーに渡し、実効値を報告する。
