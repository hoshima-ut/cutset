# prproj案件の書き出しの要件（IO-58）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

Cutsetの案件を、Premiereがそのまま開ける `.prproj` として書き出す。[編集ソフト間の引き継ぎ](../../workflow/編集ソフト間の引き継ぎ/design.md#段階と出口)の段階H6で、次の着手条件をすべて満たした場合だけ着手する。それまでは仕様だけを置く。

1. H5の後も、Cutset→Premiereの引き継ぎ表で骨格または編集の詳細に「手直し」「欠落」「値違い」が残り、困り度3の行があるか、受け手の編集者が「XMLでは受け取らない」と記録している。
2. その原因の要素を、IO-57のP3までで読めている。
3. 対象のPremiereの版を2つ以内に絞り、見本作成者が版の更新ごとに確かめる工数を確保できる。

## 受入条件

対象版のPremiereで、書き出したファイルが警告・オフライン素材・欠落の表示なしに開く（画面の写しと版を記録）。要素キーごとの判定がXML経路より悪くならない。書き出したファイルをPremiereで開いて保存し直し、Cutsetで読み戻した結果が元の案件と照合の基準で一致する。満たさない版には配布しない。

## 例外と復旧

対象外の版を選んだ場合や表現できない要素がある場合は、書き出し前に一覧で示し、XML経路を案内する。書きかけのファイルを残さない。
