# prproj案件の書き出しの設計（IO-58）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

「書き出し ▸ 引き継ぎ用」で形式に案件ファイルを選べるようになる。対象版と、欠落・値違いの一覧を確認してから書き出す。

## データと処理境界

読込の型だけから組み立てると、確認していない部分が欠けて開けないファイルになる。そのため、着手する場合は読込（IO-57）で未知の節点を捨てない木構造を採り、`write(parse(x)) == x` を保証したうえで、見本から作った最小の雛形の木に対して確認済みの節点だけを書き換える。未知の節点はそのまま残す。gzipの書き出しには共有ライブラリの `craft-gzip` を使う。置き場所はIO-57と同じくcraft-libs。ファイル入出力は持たない。
