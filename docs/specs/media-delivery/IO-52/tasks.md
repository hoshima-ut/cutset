## 具体的な試験

同一素材の別カット2本の間に5フレームの空白を置く。往復後も2配置と5フレームの空白を保ち、片方のトリムだけが戻り差分に出る。

- QA-09　同名の別テイクを別ディレクトリに置き、プロキシで編集後、別端末の原本へ戻す。カットはOTIO、字幕の本文・時刻はSRTの付属ファイルで渡し、相手が各1か所を修正して返す。 期待結果：指紋・素材時刻・配置IDから正しいテイクを確認。字幕の書体・位置は参照映像と別途照合。交換で観測不能な効果を明示。戻りでは許可した変更とその波及だけが発生する。
