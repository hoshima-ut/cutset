# IO-40 納品範囲 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

素材またはシーケンス、全体または範囲を選び、確定した版をプレビューする。

## 受入条件

前後に識別用フレームを置き、全体、In/Out、1フレームの入力で、出力先頭・末尾・フレーム数を照合。

## 例外と復旧

終端より前に始点がない空範囲は受け付けない。書き出し画面を開いた後に版が変わったら旧版か更新版かを示す。

## 参照資料と確認項目

- [A639](https://helpx.adobe.com/premiere/desktop/render-and-export/export-files/export-video.html)　範囲付きシーケンスを書き出し、出力先にある動画の先頭・末尾の識別フレームを数える。（公開手順）
