# 形式と上限の要件（IO-05）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

拡張子とストリームの内容を検査し、読めるトラックと読めない条件を提示する。

## 受入条件

同じMOV拡張子で内部コーデックの異なる素材を試す。映像、音声、アルファ、タイムコードの各ストリームを個別に照合。

## 例外と復旧

映像だけ読めない場合は対象のコーデックと利用可能な音声を示す。破損による検査失敗と未対応形式を区別する。

## 参照資料と確認項目

- [A125](https://helpx.adobe.com/premiere/desktop/organize-media/import-files/supported-file-formats.html)　同一拡張子でコーデックが異なる試験ファイルを読み、対応判定をコンテナ名だけで誤って決めないか確認する。（版混在。26.0でR3D NE、26.5でARRICORE等、27.0では一部Sony RAW対応を変更）
