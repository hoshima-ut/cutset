ハーネスの作業IDは `BUILD-IO-27`、受入IDは `AC-IO-27`。

- [ ] 関連する上流部品の挙動と、設計に追加した条件の差分を確認する。

## 具体的な試験

8-bit 4:2:0と10-bit 4:2:2の2本を同じ機器で処理し、各段の実経路、出力フレーム数と先末の画を照合する。

## 既存テストとの対応

直接対応する既存テストは、この照合では特定できていない。上記ケースを回帰試験として追加する。

## Windows ARMでのGPU・AI処理

- [ ] ARM64機でGPUあり・推論バックエンド無効の両条件を記録し、マスク追跡で実際に選んだ経路と結果のフレーム範囲を確認する。実機がなければ対応表は未検証とする。

## ARM64環境の復号とメモリ不足

- [ ] Windows ARM64でH.264とHEVCを収めたMXFを開き、復号経路を記録する。GPUメモリ不足時は影響を受ける操作と使用可能な代替経路を確認する。
