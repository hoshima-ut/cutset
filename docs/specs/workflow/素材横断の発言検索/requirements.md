# 素材横断の発言検索の要件（UX-07）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

ビン・話者・発言・任意マーカーで絞り、同じ言葉の異なるテイクを聴き分ける。

## 受入条件

同じ語を二回発した素材を二本用意する。話者で絞ると対象話者の時刻だけが残り、各行から元の音声の前後を試聴できる。

## 例外と復旧

文字起こしがない素材は未解析と表示する。検索のために未承認の外部処理へ音声を送らない。
