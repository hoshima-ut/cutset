# 往復後の差分の設計（UX-10）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

返却版をインポートし、対応する配置の開始、尺、素材点と速度の差を一覧から選んで比較再生する。

## データと処理境界

原版の配置IDと交換時の対応表を優先し、同一IDがない場合は素材参照・範囲から一致候補を提示する。時間差は元の有理数レートで計算する。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M4](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
