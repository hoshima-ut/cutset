# UX-10 往復後の差分 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

戻りデータを原版の位置・尺・素材点・速度と比べ、相違点を一覧から再生する。

## 受入条件

24fpsの交換シーケンスで一つだけIn点を一フレームずらす。再読込すると対象配置と差が示され、比較できない効果は別項目になる。

## 例外と復旧

同名クリップが複数あり一意に対応しなければ、未照合として手動選択に残す。変換不能な効果を無差分に含めない。
