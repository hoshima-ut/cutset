# 指摘から修正版への要件（UX-11）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

対象フレームに結び付くコメントへ修正版を添え、配置削除後も元版へ戻れるようにする。

## 受入条件

編集者が該当カットを直し、返信に修正版を添える。間のカットが消えたら旧版へ案内する。

## 例外と復旧

修正版から該当配置を削除した場合は元版へ戻る操作を示し、別配置に解決した状態で完了扱いにしない。
