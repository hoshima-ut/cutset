# UX-02 ビンの連続試聴 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

テイクを切り替えずに連続試聴し、採用した瞬間から原本範囲に戻る。

## 受入条件

上段で全尺を把握しながら下段で1フレーム詰める。表示範囲の変更で選択を失わない。

## 例外と復旧

再ソートで並びが変わっても選択中の素材と元フレームを維持する。欠落素材に達したときはスキップ対象を表示する。
