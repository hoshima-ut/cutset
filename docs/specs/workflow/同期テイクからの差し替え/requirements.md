# 同期テイクからの差し替えの要件（UX-03）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

外録音を保持し、同時刻の複数視点から映像だけ選び直す。

## 受入条件

歓声を含む二台の画と外録音を同期する。途中で画だけを差し替え、前後の外録音に欠落や二重再生がない。

## 例外と復旧

選択角度の収録開始が遅く全範囲を覆えない場合は不足区間を示し、無音や黒を無断で挿入しない。
