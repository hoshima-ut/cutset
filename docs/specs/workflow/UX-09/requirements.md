# UX-09 受け渡しの選択 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

各配置を編集可能なまま渡すか映像化するか選び、未対応の属性を記録する。

## 受入条件

テロップの見た目を残す選択と文言を後から直す選択を担当者が明示できる。

## 例外と復旧

相手側が表現できない効果やフォントは省略候補にせず、代替方法と見た目・再編集性への影響を選択前に示す。
