# 発言に追従する配置の設計（UX-04）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

発言を選択して字幕・挿絵の追従設定と固定BGMを確認し、移動前にどの配置が動くかプレビューする。

## データと処理境界

追従配置には発言または親配置への参照と相対時刻を、固定配置にはシーケンス時刻を保持する。循環する参照は登録できない。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M5](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
