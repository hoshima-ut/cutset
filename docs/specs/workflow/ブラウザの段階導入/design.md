# ブラウザの段階導入の設計（UX-12）

## 操作と状態遷移

能力一覧に応じて、共有版の再生・コメント、単独の粗編集、共同編集を順に利用する。接続復帰時は保留変更を確認する。

## データと処理境界

編集要求は版ID・操作ID・対象配置と期待版を持つ。デスクトップとWebで編集時間の表現を共有し、権限とホスト能力を各操作で検査する。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M6](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
