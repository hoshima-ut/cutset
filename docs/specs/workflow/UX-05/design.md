# UX-05 手編集と提案の比較 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

同じ元版の手編集案とAI案を選び、元の発言を基準に切替試聴し、採用した案だけを確定する。

## データと処理境界

案ID、基準版、元配置と素材区間を共有し、各案の試聴時刻への対応を別に計算する。試聴や案切替だけで案件に履歴を積まない。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M1](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
