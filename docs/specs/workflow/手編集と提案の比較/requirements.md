# 手編集と提案の比較の要件（UX-05）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

同じ基準版から異なる編集案を往復して試聴し、一つの案だけを採用する。

## 受入条件

尺が異なるときは各案の前後を同じ原音から聴き、選んだ版だけを確定。後続の注釈を別テイクに付け替えない。

## 例外と復旧

一方の案で基準位置が削除済みなら対応区間なしと示し、隣の別テイクへ注釈を繰り越さない。
