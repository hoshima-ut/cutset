- QA-12　同一端末・素材・プロキシで検索→試聴→トリム→字幕修正を実施。初心者と熟練者、手動とAI併用を別々に記録。 期待結果：初稿確定時間、無介助完了、意図外の変更、スクラブ入力から正しいフレームまでのp95、ドロップフレーム数、音ずれを報告する。性能の固定基準は現場が実測後に決定。
