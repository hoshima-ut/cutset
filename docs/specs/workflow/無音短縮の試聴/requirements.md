# 無音短縮の試聴の要件（UX-06）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

各候補の前後・変更尺を確認して採否を決め、字幕の文字訂正を別操作とする。

## 受入条件

検索結果から一つだけ棄却し、固有名詞の字幕だけを直しても音声を切らない。

## 例外と復旧

既に確定した操作の再送は二重に詰めず、古い版の候補には再試聴を要求する。
