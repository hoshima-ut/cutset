# UX-04 発言に追従する配置 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

字幕や挿絵を発言にアンカーし、絶対時刻に固定した音楽と区別する。

## 受入条件

発言を動かす際、追従物と固定物をプレビューする。音楽を絶対時刻に固定した場合、磁石のように自動で動かさない。

## 例外と復旧

親を削除する場合は追従解除・同時削除の選択を求める。ロックされている追従先を無断で移動しない。
