# MN-15 ヘッド追従と連続境界 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

プレイヘッドへの選択追従と連続素材の分割点の表示を別に切り替える。

## 受入条件

別素材間のカットと同一素材内の連続カットを並べ、表示を変えても映像の尺が変わらないことを確認。

## 例外と復旧

異なるテイクや素材時刻が飛ぶ境界を連続と表示しない。ロック中の配置を選んでも編集を適用しない。
