# MN-22 案件の書体置換 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

使用書体と置換先、影響する本文・字幕・配置を確認して適用する。

## 受入条件

対象書体を二つのタイトルに使い、別の書体と一緒に配置。置き換え範囲・字幕の改行を再確認。

## 例外と復旧

代替書体に無い和字やスタイルは変更前に表示し、未選択書体まで一括置換しない。
