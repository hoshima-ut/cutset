# プロキシ生成の入口の設計（MN-29）

## 操作と状態遷移

素材一覧のコンテキストから代理生成を開き、選択中の生成可能件数、プリセット、出力先、対象外理由を確認する。

## データと処理境界

メニューの可否を素材ID、映像ストリーム、読取可否、進行中の同一依頼から解決し、確定した素材だけを生成キューへ渡す。
