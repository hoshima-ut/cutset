# MN-09 アプリ設定の入口 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

OSの標準的な設定入口またはコマンド検索から項目名で設定へ移動する。

## 受入条件

対応する各OSでキーボードから外観設定を変更する。別案件にも反映され、シーケンスのレートや保存状態は変わらない。

## 例外と復旧

利用環境で使えない設定は理由を表示する。ダイアログを閉じた後は元のパネルにフォーカスを戻す。
