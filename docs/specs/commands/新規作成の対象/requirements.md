# 新規作成の対象の要件（MN-01）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

案件・シーケンス・ビン・生成素材を適切な作成先から開始する。

## 受入条件

空の案件でビンと生成素材を作成できる。ビン選択中に作成した色面はそのビンに属し、ファイル無しでもシーケンスで再生できる。

## 例外と復旧

作成中に対象ビンが消えたら挿入先を選び直す。案件が開いていない状態で案件内の項目を作らない。
