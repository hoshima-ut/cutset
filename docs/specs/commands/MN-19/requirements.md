# MN-19 再利用タイトルの作成 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

一つのタイトルから参照可能な原型を作り、他の配置で再利用する。

## 受入条件

同じ原型の参照配置二つと独立した複製一つを作る。原型本文の変更は参照配置に反映し、独立した本文は変わらない。

## 例外と復旧

使用中の原型を削除するときは使用箇所を示し、参照を壊したまま保存しない。
