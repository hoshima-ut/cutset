# MN-12 別録り素材の同期 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

同期対象を選び、共通マーカー、時刻、音声など選択素材が扱える基準と採用音源を表示する。

## データと処理境界

各素材上の同期点を共通時刻へ写し、配置オフセットの案を作る。適用前に基準音源とずれ量を確認できる。
