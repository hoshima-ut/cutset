# MN-12 別録り素材の同期 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

組み合わせ可能な素材の選択時に同期方法と採用音源を示す。

## 受入条件

二本の素材に共通の同期マーカーを付けると基準点が揃う。片方だけの場合はその方法で確定できず原本は不変。

## 例外と復旧

合わせるマーカーが複数または不足しているときは組合せを指定させ、別の基準へ自動変更しない。
