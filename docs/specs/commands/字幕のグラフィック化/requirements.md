# 字幕のグラフィック化の要件（MN-20）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

選んだ字幕をタイトルに変換し、字幕納品経路から外れる対象を明示する。

## 受入条件

変換前後で字幕サイドカーに含まれる内容とグラフィックとしての書き出しを比較。

## 例外と復旧

複製できない装飾やフォントは事前に表示する。対象外の言語や未選択キューを字幕トラックから外さない。
