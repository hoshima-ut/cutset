# 静止フレームの指定の設計（MN-10）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

タイムライン上の配置を選び、保持する素材フレームを試聴して確定する。選択した配置の尺を保持する。

## データと処理境界

再生位置や指定時刻を配置の速度・トリムに従って素材フレームへ解決し、保持フレームを配置属性として保存する。
