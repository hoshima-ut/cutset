# 静止フレームの指定の要件（MN-10）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

選択配置のどのフレームを保持するかを時刻と画で確認する。

## 受入条件

10秒のクリップを停止画にして、尺が10秒のまま指定フレームを表示するか確認。

## 例外と復旧

素材範囲外やオフラインで確認不能な候補は理由を出す。他の使用箇所には保持を適用しない。
