# MN-18 マーカー付き貼り付け — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

配置をコピーするときシーケンスマーカーを同行させるか選べる。

## 受入条件

同一区間をオン・オフで別シーケンスに貼り、マーカーの色、注記、期間、本数を比較。

## 例外と復旧

範囲外の指示と素材所有マーカーを二重に複製しない。コピー境界を跨ぐ期間マーカーの対象扱いを事前表示する。
