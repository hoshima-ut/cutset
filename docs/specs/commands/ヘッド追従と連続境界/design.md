# ヘッド追従と連続境界の設計（MN-15）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

再生ヘッド追従と連続カットの境界表示を個別にオン・オフする。ヘッド移動後の選択と境界表示を確認する。

## データと処理境界

追従はパネルの選択状態、連続境界は隣接配置の素材IDと連続する素材時刻を参照する表示状態として扱う。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/edit/src/through.rs](../../../../crates/edit/src/through.rs)。

確認した関数：[is_through_edit](../../../../crates/edit/src/through.rs)。隣接する同一素材区間の連続境界を判定でき、ヘッドに選択が追従する設定の試験もある。二つの切替を併用した画面での操作を別途検証する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
