# MN-03 保管パッケージ — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

対象シーケンスと必要素材を選び、独立して開ける引き渡し先を指定する。

## 受入条件

1本だけを選び、未使用素材と外部リンクの取扱いを確認。キャンセルで保管先に不完全な案件を残さない設計とする。

## 例外と復旧

キャンセルやコピー失敗で既存パッケージを壊さない。未完成の作業先は未完了と識別して再実行できる。
