# MN-02 案件の取り込みポリシー — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

案件設定から取り込みの方式と出力先を変更し、次の取り込みに使う既定値を確認する。

## データと処理境界

案件の既定値を各取り込み依頼へ複写する。既に取り込み済みの素材や実行中のジョブの参照先は設定変更で移動しない。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/proxies.rs](../../../../crates/engine/src/proxies.rs)。

確認した関数：[ingest](../../../../crates/engine/src/proxies.rs)。取り込み設定を使った複製と代理生成の実装がある。設定画面での範囲表示とキャンセル時の案件・ファイルの結果は別途照合する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
