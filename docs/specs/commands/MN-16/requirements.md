# MN-16 引き渡し版の簡略化 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

選択シーケンスの元版を残し、除去・展開した部分を示す。

## 受入条件

空トラック、マーカー、無効クリップがある版で、取り去る要素を一種類ずつ指定して元版と比較。

## 例外と復旧

対象に含まれるネストや依存が簡略化できない場合は対象を示し、元版を編集しない。
