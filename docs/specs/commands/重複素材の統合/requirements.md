# 重複素材の統合の要件（MN-07）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

対象範囲を明示し、重複した素材参照またはビンをまとめる。

## 受入条件

異なる階層に同名ビンを置き、それぞれの使用中のカットと所属を維持できたか照合。

## 例外と復旧

選択範囲外の同名ビンは統合対象にしない。確認後に候補が変更されたら件数を再計算する。
