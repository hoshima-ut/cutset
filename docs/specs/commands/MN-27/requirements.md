# MN-27 レビュー用パネル — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

版・コメント・参加状態を確認し、利用可能なレビュー先を開く。

## 受入条件

共有を切断した状態で開くと接続条件を示す。再接続後に旧版コメントから該当フレームを開ける。

## 例外と復旧

切断・権限失効・版削除を別々に扱い、理由と再接続先を示す。別版の同時刻へ自動移動しない。
