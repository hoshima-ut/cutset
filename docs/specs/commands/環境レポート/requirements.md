# 環境レポートの要件（MN-28）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

ハードウェアと素材処理の診断を開き、原因と共有可能な情報を選ぶ。

## 受入条件

案件未作成で実行し、検出した機器・ドライバーを確認。中止とローカル保存の結果を区別。

## 例外と復旧

取得できない機器情報は未取得として表示する。保存の取消でファイルを作成せず、自動送信しない。
