# テンプレートを書き出すの要件（MN-21）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

公開可能な属性と依存するフォント・素材を表示してタイトルひな型を作る。

## 受入条件

自作の交換可能なタイトル一件からひな型を作り、再取り込みすると公開した属性だけを編集できる。複数選択・非対応形式で勝手に一件だけを書き出さない。

## 例外と復旧

配布できないフォントや参照切れの画像は同梱済みと表示しない。必要な依存に問題があれば修正または除外を促す。
