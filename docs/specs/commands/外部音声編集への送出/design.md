# 外部音声編集への送出の設計（MN-08）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

選択配置の音声を編集するか、シーケンス全体をトラック単位で渡すかを選び、出力先と戻り先を確認する。

## データと処理境界

単体は配置IDと素材区間、全体はシーケンス版、トラック対応、開始時刻と各ステムの識別子を記録する。

## 既存実装との対応

方針は「上流対応を要確認」。対象マイルストーンは[M5](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
