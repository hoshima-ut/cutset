# Premiere 26.x と Cutset の機能仕様の照合

2026年11月27日確認。AREAの記事は10月19日公開で、本文の基準日は8月です。記事の6項目と補足の生成メディアを、Adobeの公開資料とCutsetの既存仕様（`eef8094d`）で照合しました。表の右端はCutsetの開発・受入試験で満たす項目です。別途、11月の更新内容をまとめています。[AREAの記事](https://area-p.com/machine_blog/20261021-541/) ・ [Adobeのリリースノート](https://helpx.adobe.com/premiere/desktop/whats-new/release-notes.html) ・ [Premiere 27.0 との照合](premiere-27-0.md)

| 機能 | Adobeで確認した範囲 | Cutsetの既存仕様 | 具体化した操作・受入条件 |
| --- | --- | --- | --- |
| オブジェクトマスク | 26.0で被写体マスク、26.2でシャープ／スムーズの切替、26.3以降で追跡・検出を改善。[境界モード](https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-masks/apply-sharp-and-smooth-modes-in-object-masking.html) | 手修正アンカーを残して追跡する要件があった。既存エンジンのマスク処理は再利用候補。 | 硬い輪郭・毛先の半透明度、遮蔽後の復帰、再追跡後の手修正保持。[被写体の追跡](effects/被写体の追跡/requirements.md) |
| 映像・環境音の生成延長 | 25.2で提供。26.5で対応する入力の解像度、フレームレート、HDRを拡張。映像は最大2秒、環境音は最大10秒。会話や音楽の生成延長には制約がある。[初出の告知](https://blog.adobe.com/en/publish/2025/04/02/introducing-new-ai-powered-features-workflow-enhancements-premiere-pro-after-effects) ・ [生成延長FAQ](https://helpx.adobe.com/premiere/desktop/edit-projects/edit-with-generative-ai/generative-extend-faq.html) | 元素材と生成区間の分離、モデルや選択版の記録を仕様化済み。 | 映像・環境音の個別選択、提供モデルごとの上限、部分取り消し、原音の保全。[クリップ端の生成延長](ai-plugin/生成素材の来歴/requirements.md#クリップ端の生成延長) |
| 素材検索・類似画検索 | 25.2の映像内容・発話・属性による検索に、25.6で音の内容による検索と参照フレームに似たカットの検索が加わった。[Adobeの25.6告知](https://blog.adobe.com/en/publish/2025/11/19/adobe-premiere-adds-smarter-search-faster-edits-seamless-collaboration) | 一致箇所への移動、映像・音・発話・属性、参照フレームの資料があった。 | 音と発話を別の区間で照合し、類似画から原本の該当時刻に移動。未解析と結果0件を区別。[内容による素材検索](media-delivery/内容による素材検索/requirements.md) |
| 一語ずつ表示する字幕 | 26.3で発話に合わせて一語ずつ表示する字幕を追加。Adobeの手順で確認できるのは語単位の表示切替と書式設定。[一語字幕の作成](https://helpx.adobe.com/premiere/desktop/add-text-images/insert-captions/create-single-word-captions.html) | 一語表示と日本語の分割に関する確認項目があった。 | 日本語の語境界・フレーム境界での表示切替、時刻の手修正、焼き込みと字幕ファイルの出力内容。[字幕の手編集](captions/字幕の手編集/requirements.md) |
| ボードからシーケンスを作成 | 26.0でボードからの素材取込、26.3で複数取込時に選択順でシーケンスを作る設定を追加。[Boardsからの読み込み手順](https://helpx.adobe.com/premiere/desktop/organize-media/import-files/import-media-from-firefly-boards.html) | 素材の選択順と登録数、利用許諾の状態を確認する項目があった。 | 選択順と通信完了順が異なるケース、各クリップの単独編集、欠落素材の再試行、素材登録のみの取込。[共有素材・利用権](media-delivery/共有素材・利用権/requirements.md) |
| シーケンス内の配置一覧 | 26.2でSequence Indexを追加。条件検索、該当箇所への移動、一覧のCSV出力を備える。[Sequence Indexの手順](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/navigate-timelines-with-sequence-index.html) | 同名クリップを区別する要件、短いカット・オフライン素材・CSVの照合項目があった。 | 1フレームのカット、表示列・順序とCSVの対応、削除済みの行を選んだ場合の更新。[配置の一覧](media-delivery/配置の一覧/requirements.md) |
| 指示文からの映像・効果音生成 | 8月時点の記事ではベータ。Adobeは9月の26.5で映像・効果音をタイムラインから生成する機能を案内。11月に確認した日本語の操作手順ではツール名に「Beta」と表示している。[9月の告知](https://blog.adobe.com/en/publish/2026/09/08/generate-create-directly-in-your-timeline-with-new-ai-powered-innovations-in-premiere-after-effects) ・ [生成の操作手順](https://helpx.adobe.com/jp/premiere/desktop/edit-projects/edit-with-generative-ai/generate-media-with-generative-media-tool.html) | 来歴・使用量・配置への反映の確認項目があった。 | 生成と配置確定を分け、映像・効果音を独立編集する。候補の選択、取消後の遅延応答、保存後のオフライン再生を試験する。[タイムラインからの映像・効果音生成](ai-plugin/生成素材の来歴/requirements.md#タイムラインからの映像効果音生成) |

これらの試験は各機能の「作業・試験」に未実施として記録しています。生成サービスとアカウントの利用条件はプラグインごとに確認します。Cutsetの受入試験は固定素材と模擬応答で再現できるように設計します。
