# 映像・音声・形式別の実装対象

この表は個別候補を実装・照合する単位に分けたもの。納品可能と表示する単位はコンテナ、ストリームの種類、プロファイル、ビット深度、読み書きの方向、ホストの組合せとする。現在使える経路は [上流の形式対応表](../../reference/filmcraft/file-format-parity.md)、[コーデック対応表](../../reference/filmcraft/codec-parity.md)、[ハードウェア対応表](../../reference/filmcraft/hardware-parity.md) で確認する。候補全体を現在のサポート表として扱わない。

## 映像効果の候補

各行は FX-01、FX-02 に属する。パラメーターを変え、時間範囲・入力フレーム・効果順を固定して処理前後を照合する。保存して開き直した後も、選択・順序・バイパス・キーの設定が一致しなければならない。個別バリアントの対応状況を一つずつ記録する。

| 処理 | 個別に試すバリアント | 操作と観測 |
| --- | --- | --- |
| 信号と照明 | レベル補正、指定輝度の抽出、ゲインとオフセット、画面内光源 | 階調付きの球を用い、閾値で抜ける範囲と光源を動かした陰影を調べる。 |
| ぼかし・鮮鋭 | ガウス、方向、焦点面、絞り形状、濃淡マップ、RGBA別、鮮鋭化、アンシャープ、インターレースちらつき低減 | 点光源と細線で半径、方向、光点の形、赤だけのにじみ、オーバーシュートを見る。 |
| 色処理 | 色調補正、輝度・コントラスト、映像信号の上限、二色着色、周辺減光、ASC CDL、ガンマ、二値化、単色保持、色置換、モノクロ、RGB混合、反転 | カラーバーと階調を入力に、設定した色域・チャンネルだけが変わるか調べる。 |
| 形状変形 | 波、ねじり、乱流変形、球面変形、鏡像、レンズ歪み、四隅変形、手ぶれ補正、拡大レンズ | 格子の四隅・中心を固定点として、それぞれの変形半径・向き・外側の扱いを調べる。 |
| グラデーション・マット | 線形、放射、四点、反復、角丸切抜き、境界線、クロマキー、明度キー、別トラックの濃淡／アルファ、ロゴ形状、アルファ倍率 | 半透明のロゴと三層の映像を用い、中間アルファと下層の透け方を比較する。 |
| 光と残像 | ハイライト拡散、体積光、RGBのずれ、光漏れ、きらめき、輪郭発光、発光残像、レンズフレア | 移動する白点を使い、発光の中心・方向・残存フレーム数が設定と連動するか測る。 |
| 質感 | 時間変化するノイズ、長い影、落ち影、エッジの荒れ、色数低減、モザイク、輪郭抽出、浮き彫り、筆致、点滅 | 単色の背景と細い透明文字で境界・粒度・影方向を比較。乱数を含む採用値は保存後に再現する。 |
| 動きと座標 | 三軸回転、揺れ、ゆらぎ、スピン、移動、拡大縮小、余白、上下左右反転、端の回り込み、アンカー変形、自動画角、平面の三次元傾斜 | 左右で文字が異なる絵を使い、軸、端の画素、対象追従、アンカー位置を確認する。 |
| 時間・注記・配置 | 更新頻度の量子化、濃淡順の出現、複写、文字注記、時刻・属性の焼込み、ログ変換、寸法の自動整列 | フレーム番号を描いた素材で反復回数とソース時刻を確認し、配置の全尺が保たれるか調べる。 |
| 球面 | 鮮鋭、回転、投影変換、平面の貼付、発光、フラクタルノイズ、信号乱れ、ノイズ低減、色勾配、色収差、ぼかし | 極と継ぎ目を跨ぐ被写体で球面の連続性、左右眼、基準方位を比較する。 |

## 編集点に置く切替

FX-16 と ED-40 を基本とし、片側で必要な余白がない場合は見た目と許容長を示す。以下の各方式で開始・中間・終了の三枚、透明領域、幾何学的な境界位置を照合する。FX-17 の人物補間には遮蔽、分析の取消と失敗報告を追加する。

| 方式 | 個別候補と変える値 |
| --- | --- |
| 出現する動き | 移動、ばね、回転、引き寄せ、飛び出し、折りたたみ、反転、ブロック分割。軌道、揃え方、イージングを変更する。 |
| 混合 | 交差フェード、加算、フィルム風カーブ、白・黒・任意色を経由、輝度順、アルファ焼き、ぼかし混合、モザイク、人物の顔・動きの補間。透明ロゴでも中間像を確認する。 |
| 乱れ・歪み | アナログ信号破損、受像機の消灯、液体変形、万華鏡、ざらつき、デジタル破損、ガラス分割、ちらつき、振動、不規則変形。揺れ幅・分割数・種を固定して照合する。 |
| 球面 | 全球ぼかし、ランダムブロック、球面ズーム、光線、光漏れ、絞り、濃淡境界、色漏れ。極・経度の継ぎ目で境界が連続する。 |
| 光・ぼかし | ズーム、ストライプ、明暗反転、光線、放射、蛍光残像、光の走査、漏光、レンズ、発光、閃光、フレア、方向ぼけ、二画面のズーム、色漏れ、色焼き。軸・閾値・進行比を振る。 |
| 面の置換 | 急速なパン、伸長、分割、ロール、押出、フィルム送り、三次元ロール、回転して復帰する切替、スライド。進入と退出する側の端を追う。 |
| 形と視点の補間 | 形状の対応、移動軌道、カメラ移動を編集点の両側の位置・大きさに合わせる。 |
| 文字 | 一文字ずつ表示、文字位置のアニメーション。濁点・結合文字・絵文字を含む本文で分割単位を照合する。 |
| 形状で置換 | 波、スライス、ページめくり、鏡、ブラインド、枠、三軸回転、形状によるディゾルブ。方向、境界幅、羽根幅、中心と時間を変える。 |
| 境界を移動 | ストレッチ、星、柔らかい境界、放射、段、パネル、発光線、絞り、グラデーション、図形。進入方向、中心と幅を調整する。 |

## 旧版の効果

FX-18 は効果と遷移を別々に識別し、「現行」「旧版を再現」「代替へ移行」「実行できず設定保持」を区別する。旧版・現行版の両方を使った自作案件を読み、元ID、パラメーター、キーフレームと移行した箇所を記録する。処理器を提供できない場合は削除予定として表示せず、編集者の置換または原画付き参照を選べる。参照元の版で分類が変わった項目は[資料台帳](../data/sources.json)の A388–A390、A429–A430 を起点に調べる。

## 音響処理器

AU-13 を基本とし、それぞれの処理を配置、トラック、バスの対応箇所で使う。AU-14 の計測器ではチャンネル、測定窓、単位を記録する。

| 処理群 | 個別対象 | 受入の入力と観測 |
| --- | --- | --- |
| 利得と経路 | 全体の増幅、チャンネル別利得、行列混合、右または左から他方への複写、左右交換、極性反転 | 左右で違う時刻のインパルスを入力し、宛先・符号・レベルを比べる。 |
| ダイナミクス | 歯擦音抑制、ゲートと圧縮、任意の入出力カーブ、ピークリミッター、多帯域圧縮、単帯域圧縮、飽和を伴う圧縮 | 会話と急な強音から閾値通過時刻、アタック・リリース、帯域ごとのゲイン変化を測る。 |
| ディレイ | 単一、減衰と帯域変化を伴う反復、多タップ | 単発パルスの後で設定した各時刻の反復とフィードバックの減衰を検出する。 |
| EQ・帯域 | 帯域通過、低域・高域シェルフ、高域通過、低域通過、ノッチ、周波数領域フィルター、グラフィックEQ、パラメトリックEQ、特性を選べるフィルター | スイープの減衰帯とQ、ハムだけを落とした結果を確認する。 |
| 変調 | コーラス、フランジャー、フェイザー | 定常音に対する変調周波数、深さ、原音比、左右位相を変える。 |
| 修復 | クリック除去、電源ハム、定常ノイズ、残響低減 | 既知のノイズだけを加えた短い台詞で、劣化量と原音の変化を照合する。 |
| 残響 | 畳み込み、アルゴリズム、サラウンド出力 | 拍手の残響尾とチャンネルごとの開始・終了を確認する。 |
| 音色・計測 | 歪み、ギター用処理、統合ラウドネス履歴、最終調整、声の帯域補正、ステレオ幅、ピッチシフト | 極性の異なる音と中央定位の声を使い、モノ合成、音高、総尺、統合レベルを比較する。 |

## 納品時の独立した判定点

1. **映像**（IO-42、IO-44） 番号付きフレームの尺と時基、走査、画素比、色深度、アルファだけの出力、補間方法を再読込で確認する。
2. **符号化**（IO-27、IO-42） 実際のエンコーダー、プロファイル、レベル、GOP長、CBR/VBRと目標ビットレートを記録し、動きの多い区間も再生して検査する。
3. **HDR**（CO-03、IO-44） 出力色空間、グラフィックの白レベル、原色、マスタリング表示器の輝度範囲、最大コンテンツ・フレーム平均輝度のタグと値を読み返す。
4. **音声・多重化**（IO-43、AU-18） ストリームの種類・数、サンプルレート、チャンネル割当、コンテナと単独出力を確認する。
5. **字幕・付帯情報**（IO-46、IO-49） 焼き込み・別ファイル・埋込み、字幕レート、メタデータを記録する。配信用の透かしや来歴は選んだ出力だけに付く。
6. **生成後の処理**（IO-26、IO-45、IO-48） 原本または代理、キャッシュ再利用、案件への再取り込み、書き出し先と基準版をジョブ履歴から追跡する。
