# 三点・四点編集の要件（ED-14）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

素材側と配置先の範囲から挿入点と尺を求め、矛盾する指定は選択を求める。

## 受入条件

24fps素材の24フレームを空の12フレーム範囲へ。範囲を優先した場合と尺に合わせて速度を変えた場合を見分ける。

## 例外と復旧

ゼロ尺や逆順の範囲、素材余白を超える解を検出したら配置を加えず、どの指定を変更するか示す。

## 参照資料と確認項目

Cutsetの製品要件。
