# ED-01 作業の切替 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

案件・現在位置を保持して素材準備、編集、納品へ移る。

## 受入条件

編集と書き出しを往復して同じタイムラインに戻る。

## 例外と復旧

作業面の切替時に未確定の納品設定があれば残留状態を表示し、誤ってキューに投入しない。
