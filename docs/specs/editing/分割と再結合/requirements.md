# 分割と再結合の要件（ED-19）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

プレイヘッドで対象配置を分割し、同一素材の連続境界から結合できる。

## 受入条件

先に分割した連続素材は戻せる。異なるテイクの境界を誤結合しない。

## 例外と復旧

分割点が配置端なら空配置を作らない。間にギャップや異なる素材があれば結合できない理由を返す。
