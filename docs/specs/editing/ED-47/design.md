# ED-47 共同作業者管理 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

案件所有者が参加者と役割を指定し、受け手が招待を受諾する。素材の同期状況を参加状況とは別に示す。

## データと処理境界

権限は案件IDと参加者IDの組で判定する。メディアへの到達可否を端末ごとに管理し、共有権限を再利用してローカルパスを公開しない。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M6](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
