# 音声先行・映像先行のカットの要件（ED-31）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

音声と映像の境界を独立にトリムし、同じ時刻の映像と原音の同期を保つ。

## 受入条件

次の声の開始を3フレーム前へ。画の切替時刻、切替後の口と声の同期、BGMの位置、全体尺は不変。

## 例外と復旧

音声の前側に余白が不足していれば実現できる先行量を示す。保護されたBGMへ移動を伝播しない。

## 参照資料と確認項目

- [A238](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)　次話者の声を3フレーム早く入れ、前話者の声を次カットまで残す別案と、映像切替後の口と声の同期を比較する。（公開手順）
