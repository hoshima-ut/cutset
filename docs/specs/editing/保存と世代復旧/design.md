# 保存と世代復旧の設計（ED-46）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

通常保存、別名保存、前回保存版の読み直し、自動保存世代からの復旧を選び、対象パスと世代を確認する。

## データと処理境界

現在の作業版、保存済み版、自動保存の世代を別に参照する。新しい保存が完了してから既存ファイルを置換する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M2](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/autosave.rs](../../../../crates/engine/src/autosave.rs)。

確認した関数：[load_candidate](../../../../crates/engine/src/autosave.rs)。復旧候補のスナップショットは上限付きで読み込んでデコードする。スナップショットの保存失敗時にも元版を維持する回帰試験がある。編集者が各版の内容を識別できるかは実機で確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
