# 台本とテイクの対応付けの要件（ED-60）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

台本のテキストを案件に取り込み、各セリフの行にどのテイクのどの範囲が対応するかを縦の線で示す。編集者は台本の行から、そのセリフを撮ったテイクを選んで再生・配置できる。上流FilmCraftで実装済みの機能を、Cutsetの編集者の作業で使えるかを確かめる。

## 受入条件

テキストを貼り付けて台本を作り、二つのテイクを行範囲に割り当てる。行を選ぶと対応するテイクの開始位置が分かり、テイクの範囲を縮めても行・注記・色は元の行IDのまま残る。保存して開き直しても同じ対応が残り、元素材が消えたテイクは欠落として示され、再接続できる。

## 例外と復旧

元素材が見つからないテイクは削除せず欠落として表示し、案件の素材への再接続を案内する。壊れた台本データは読込時に拒否し、案件全体は開けるようにする。
