# ED-27 リップルトリム — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

端を伸縮した量だけ連動対象の後続配置をずらす。

## 受入条件

30フレームの中央クリップを末尾から3フレーム短縮。後続も3フレーム前、対象全体尺も3フレーム短い。

## 例外と復旧

ロックした配置との衝突や余白不足は仮表示に反映し、前半だけを変更した状態で終了しない。

## 参照資料と確認項目

- [A234](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-ripple-edits.html)　リップルトリムで中央を4フレーム詰め、同期ロック対象の後続が同じ4フレームだけ前へ動くか照合する。（26.5でリップルトリム中の動的表示をオフにできる。27.0のTimeline設定と区別）
