# 二次補正の設計（CO-08）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

色を採取して色相・彩度・明度範囲を広げ、マット表示で選択範囲を確認する。境界を調整してから部分補正とビネットを試す。

## データと処理境界

抽出条件と補正量を別に保存し、抽出結果を0〜1の被覆率として補正結果へ混合する。ビネット位置・半径は画面座標で保持する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/color.rs](../../../../crates/engine/src/color.rs)。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。

## HSLマスクと他のマスクを組み合わせる

色相、彩度、輝度による被覆率を形状・追跡マスクと組み合わせ、合成順と反転を保存する。補正前に最終マットを表示する。
