# CO-03 出力と表示色 — 設計

## 操作と状態遷移

出力規格を選んでから、プレビューに使うモニタープロファイルを切り替える。ファイルのタグとモニターの表示条件を個別に表示する。

## データと処理境界

書き出し側は原色・伝達特性・行列・レンジを出力に設定する。モニター変換は表示枝だけに適用し、書き出しフレームへ焼き込まない。
