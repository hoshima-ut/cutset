# CO-06 色のカーブ — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

スコープを見ながらRGBまたは色相別のカーブに点を追加し、対象色域だけを変える。数値入力で点の位置を微調整する。

## データと処理境界

カーブ種別ごとに入力軸・出力軸と制御点列を保存する。色相の端は同じ色へつながるよう循環評価し、制御点間を一意に補間する。
