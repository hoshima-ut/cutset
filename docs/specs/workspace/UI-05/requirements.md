## 目的と範囲

案件、素材、選択順、参照または複製を確認して取り込みを一度に確定する。

## 受入条件

素材選択、選んだ順序、取り込み先、コピー／参照の区別を確認できる。キャンセル後に取り込み途中のクリップが残らない。

## 例外と復旧

コピー途中の容量不足は対象ファイル名と必要容量を表示する。今回作った一時コピーを片付け、既存ファイルを保持する。
