# 文字・値の入力の要件（UI-11）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

直接入力とドラッグ調整を用意し、日本語の未確定入力を編集中の対象に閉じ込める。

## 受入条件

数値の直接入力、ドラッグ調整、修飾キー、初期値復帰を使い分ける。日本語IMEで未確定のEnter/Escは入力に渡し、選択中の別クリップまで変更しない。

## 例外と復旧

無効な数値、範囲外値、未完の変換を破棄した場合は最後に確定した値を残す。
