# 案件の再開の要件（UI-01）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

最近開いた案件を選んで編集を再開する。参照先が移動したときは元の案件を特定して再接続する。

## 受入条件

最近使った案件から一手で再開。移動済みなら所在の指定、初回なら素材から作成へ進む。空案件を作る人に先行アップロードを要求しない。

## 例外と復旧

移動先に同名の別案件があれば識別情報を表示し、利用者の選択前に履歴を書き換えない。
