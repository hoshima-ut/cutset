# UI-18 球面映像の試聴 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

平面・球面、視野角、ステレオ配置を区別し、試聴方向を操作する。

## 受入条件

平面、180度／360度、単眼／立体の素材とシーケンスの指定を区別。視点・パン・回転・空間音声の向き、投影の継ぎ目、納品メタデータを再生器で確認する。

## 例外と復旧

ステレオ配置情報が不明なら左右眼を選ぶまで単眼の確認表示にし、推定した設定を納品値に保存しない。
