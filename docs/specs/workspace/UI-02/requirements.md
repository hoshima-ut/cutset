# UI-02 編集ツールの作用範囲 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

ポインターをクリップ中央・端・隣接境界へ移したときに対象と動く範囲を予告する。

## 受入条件

クリップ中央・端・境界でカーソルと操作名が変わる。リップルでは動く下流範囲、ロールでは両側の境界を強調。Escでドラッグをやめれば編集前の状態。

## 例外と復旧

操作中に対象がロックされた場合はプレビューを破棄し、動かせなかった行を表示する。
