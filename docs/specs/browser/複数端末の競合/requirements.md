# 複数端末の競合の要件（WB-05）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

操作IDと基準版で重複を除き、独立変更を統合し、重なる編集は双方を比較可能にする。

## 受入条件

一人がオフラインの間に相手が同じ配置を削除。再接続しても他人の作業を消さず、二つの意図を確認できる。

## 例外と復旧

競合箇所は利用者が決めるまで保留し、他端末の編集を一方的に取り消さない。再送後も未解決の操作と基準版を保持する。
