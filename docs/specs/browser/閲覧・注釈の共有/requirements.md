# 閲覧・注釈の共有の要件（WB-01）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

確定版から作る試聴用素材に、期限と閲覧・注釈権限を設定する。

## 受入条件

閲覧者が編集を書き込めず、権限を失った利用者は新規取得できない。共有前に対象版・素材範囲を確認できる。

## 例外と復旧

失効後の新規取得を拒否する。既に受信済みのメディアを回収できると表示しない。参照素材生成の途中失敗では未完成版を公開しない。

## 参照資料と確認項目

Cutsetの製品要件。
