# WB-02 フレームコメントの追従 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

レビュー画面で対象フレームにコメントを付け、後の版では対応位置と元版の双方へジャンプできる。対応が不明なコメントは要確認欄に表示する。

## データと処理境界

コメントは版ID・配置ID・ソース時刻と当時のシーケンス時刻を保持する。編集後は配置の時間写像を参照し、同一素材の他配置を自動選択しない。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M6](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/marker_edit.rs](../../../../crates/engine/src/marker_edit.rs)。

確認した関数：[run](../../../../crates/engine/src/marker_edit.rs)。メディアまたはシーケンスの所有者を特定してマーカーを更新する。共有コメントの版・配置・素材フレームの対応と過去版への移動は追加する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
