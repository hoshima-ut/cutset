# WB-02 フレームコメントの追従 — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

版、配置ID、素材範囲でコメントを固定し、配置終了後は元版に戻る。

## 受入条件

リップル後も同じ歓声を指す。対象がなくなった指摘は旧版で開き、同名ファイルへ自動移動しない。

## 例外と復旧

配置が削除された、または逆再生や停止で候補が複数に分かれた場合は旧版と候補を提示し、利用者が対応を確定する。
