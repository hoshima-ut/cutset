# WB-05 複数端末の競合 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

複数端末の変更を更新履歴で確認する。接続復帰時は独立変更を統合し、削除と修正が重なる箇所は双方の内容を並べて解決案を選ぶ。

## データと処理境界

操作ID、作者、基準版、読取・変更した対象IDを保存する。同じ操作の再受信を除外し、同一配置の削除・更新や時間範囲の衝突をエンジンで判定する。

## 既存実装との対応

方針は「新規設計」。対象マイルストーンは[M6](../../../development/milestones.md)。

上流コードの照合先：[apps/filmcraft-web/src/host.rs](../../../../apps/filmcraft-web/src/host.rs)。

確認した関数：[sync](../../../../apps/filmcraft-web/src/host.rs)。ホストに書込結果と案件の変更状態を通知する単端末の経路。端末横断の操作ID、因果関係の保存、再送除外、削除と変更の競合解消は新規設計。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
