# ローカル保存と同期の要件（WB-04）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

再生成可能なブラウザキャッシュと永続化・同期が必要な編集記録を区別する。

## 受入条件

ストレージ上限、サイトデータの削除、未同期のタブ終了を別々に試す。未保存の操作を「保存済み」と表示しない。

## 例外と復旧

容量不足では先に再生成可能キャッシュを整理し、永続化できなければ未保存と表示する。サイトデータ消去時の復旧は同期済み範囲と手元のバックアップに限定する。
