# キーとトラックマットの設計（FX-13）

## 操作と状態遷移

キー色を採取するかマットトラックを指定し、白黒のマットを表示する。境界調整の後、背景を白・黒に切り替えて縁を確認する。

## データと処理境界

クロマキーは色から被覆率、トラックマットは選択したアルファまたは輝度から被覆率を得る。マット用入力と出力に表示するトラックの可視状態を分ける。
