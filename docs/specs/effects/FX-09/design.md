# FX-09 透明度とブレンド — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

前景の不透明度とブレンドモードを選び、背景上の合成結果とアルファ表示を切り替える。

## データと処理境界

設定した合成空間で前景・背景色にブレンド式を適用し、被覆率とアルファで合成する。入出力で直線・乗算済みアルファの表現を明示する。
