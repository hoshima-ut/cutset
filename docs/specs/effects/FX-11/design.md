# FX-11 マスクの共有と合成 — 設計

## 操作と状態遷移

マスクを複写して別の効果へ割り当て、輪郭ごとに追加・減算を選ぶ。マスク名を選択して画面の輪郭と対応させる。

## データと処理境界

合成順と各マスクの演算を記録する。独立複製を選んだ場合は別IDを付け、元輪郭との変更共有を切る。
