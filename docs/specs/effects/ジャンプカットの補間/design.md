# ジャンプカットの補間の設計（FX-17）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

人物の編集点を選んで短い補間候補を生成し、元のカットと交互に再生する。採用または解除で編集点の設定を切り替える。

## データと処理境界

前後の素材ID・範囲と補間設定から解析結果を作り、映像だけに適用する。会話音声は別途指定がある場合にだけ変更する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/render/src/flow.rs](../../../../crates/render/src/flow.rs)。

確認した関数：[interpolate](../../../../crates/render/src/flow.rs)。前後の画をオプティカルフローで補間するMorph Cutの描画経路がある。顔の認識やカット間の対応品質を保証するものではない。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。
