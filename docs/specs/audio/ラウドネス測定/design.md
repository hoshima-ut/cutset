# ラウドネス測定の設計（AU-14）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

測定範囲と納品目標を設定し、全区間を解析する。統合値、トゥルーピーク、最大サンプルピークと不足・超過を別々に表示する。

## データと処理境界

出力バス・チャンネル割当・対象区間・測定方式と測定値を対応付ける。ゲインやミックス変更後は旧結果を識別し、再測定する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。
