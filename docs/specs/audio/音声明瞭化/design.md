# 音声明瞭化の設計（AU-09）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

会話区間を指定してノイズ・残響処理を試し、原音と処理音の混合比を調整する。バイパスと同じ再生位置で比較できる。

## データと処理境界

解析結果と音声レンダーを素材・対象サンプル範囲・設定で区別し、処理遅延を補正して原音と混合する。確定後の再生に必要な結果を明示する。

## 既存実装との対応

方針は「上流対応を要確認」。対象マイルストーンは[M5](../../../development/milestones.md)。

この機能に直接対応する既存実装は台帳で未特定。既存の処理との境界を着手時に確認する。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。

<a id="premiere-27-6"></a>

## 会話音声の成分別調整（27.0との照合）

対応モデルの音声成分と調整可能な値を表示する。設定は元の録音に紐付け、処理前後を同じサンプル位置から試聴できる。

<a id="premiere-27-7"></a>

## 重なって話す二人の声を分離する（27.0との照合）

単一のミックスから時間原点を共有する二つの音声素材を作る。各話者を個別トラックへ送り、元の録音との二重再生を防ぐ。
