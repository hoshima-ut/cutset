ハーネスの作業IDは `BUILD-AU-09`、受入IDは `AC-AU-09`。

- [ ] 設計した入出力を実装する場所と、その機能を呼び出す入口を決める。
- [ ] [状態遷移とデータ境界](design.md)を実装経路で照合し、不足分を実装する。
- [ ] 下の入力で結果を照合し、[例外と復旧](requirements.md#例外と復旧)のケースを再現する。実行した版と結果を記録する。

## 具体的な試験

同じ発話に定常ノイズを足し、直前にノイズのみの区間を含める。混合0%は原音と一致し、処理後の発話開始位置はずれず、ノイズ区間の実効値を前後比較できる。

## 既存テストとの対応

直接対応する既存テストは、この照合では特定できていない。上記ケースを回帰試験として追加する。

<a id="premiere-27-6"></a>

## 会話音声の成分別調整（27.0との照合）

- [ ] 背景音のある会話を使い、対応する成分を一つだけ調整する。バイパスで原音に戻り、保存後に各成分の値を復元できる。

<a id="premiere-27-7"></a>

## 重なって話す二人の声を分離する（27.0との照合）

- [ ] 1秒間発話が重なる二人の試料を使い、片方ずつソロ再生できることを確認する。片方の移動は他方に影響せず、一度のUndoで元の配線に戻る。
