# ミックスオートメーションの設計（AU-07）

## 操作と状態遷移

モードを指定して再生し、フェーダーの押下、移動、解放、再生停止を記録する。記録後はレーンを表示して書込み範囲を確認する。

## データと処理境界

モード、入力ジェスチャー、再生位置から書込区間を決める。Readは既存値を評価し、Touchは解放後に既存カーブへ復帰、Latchは停止まで最終入力値を保持する。
