# ダッキングの設計（AU-10）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

基準となる会話トラックと下げる音楽を選び、減衰量・立ち下がり・復帰を指定してカーブを生成する。生成後のキーを試聴し個別に修正する。

## データと処理境界

会話の区間と設定からゲイン包絡を生成し、生成キーと手修正を区別する。再生成時は変更予定の区間と保護したキーを表示する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/audio-dsp/src/ducking.rs](../../../../crates/audio-dsp/src/ducking.rs)。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。

## 編集に追従する自動ダッキング

基準音声の追加、端のトリム、ミュートで該当時間と復帰区間の自動キーを更新する。保護した手動キーを維持する。
