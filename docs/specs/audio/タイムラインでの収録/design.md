# タイムラインでの収録の設計（AU-15）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

入力機器、宛先トラック、開始点を確認して待機する。カウント後に収録し、停止後に新規テイクの波形と配置位置を確認する。

## データと処理境界

録音中の一時音声を確定後に素材登録し、実際の最初のサンプルと配置時刻を記録する。録り直しも別素材として保持する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/voiceover.rs](../../../../crates/engine/src/voiceover.rs)。

編集画面・支援技術・エージェント操作の共通条件は[分野別の操作契約](../../shared/interaction.md)を適用する。

## 録音中の波形をタイムラインに表示する（27.0との照合）

ミキサー録音とボイスオーバーの入力を短いブロックで集計し、収録中の位置まで波形を描く。取り込んだサンプル数で最終波形と位置を確定する。
