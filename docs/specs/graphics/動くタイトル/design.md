# 動くタイトルの設計（GR-04）

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

タイトルの変形キーを打つかロールを選び、開始・終了の静止と画面外の余白を設定する。先頭・末尾・中間をスクラブする。

## データと処理境界

レイヤーの位置を配置ローカル時刻から評価する。ロール距離は組版後の高さと表示枠から求め、静止区間を除く移動区間に配分する。
