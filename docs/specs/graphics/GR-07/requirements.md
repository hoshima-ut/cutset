# GR-07 タイトルテンプレート — 要件

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 目的と範囲

所持するテンプレートを登録し、公開されたパラメーターだけを配置ごとに編集する。

## 受入条件

テンプレートを二度配置し、個別値・未公開項目・必要フォントと依存素材を確認する。

## 例外と復旧

必要な書体や画像が不足した場合は該当リソースを表示する。未公開パラメーターの書込要求は拒否し、既存の公開値を保持する。

## 参照資料と確認項目

- [A322](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/about-motion-graphics-templates.html)　同じ下帯テンプレートを二度置き、各配置の名前を別々に表示できるか確認する。（公開手順）
- [A323](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/install-motion-graphics-templates.html)　ローカルの.mogrtを取り込み、テンプレート名を検索して新たに配置できるか試す。（公開手順）
- [A324](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/add-motion-graphic-templates-to-a-sequence.html)　既存カット上の空き映像トラックへテンプレートを置き、選んだ開始フレームから見えるか確かめる。（公開手順）
- [A325](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/organize-motion-graphics-templates.html)　用途別の保存場所を切り替え、スポーツ用にまとめたテンプレートだけを見つけられるか確認する。（公開手順）
- [A326](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/browse-and-sort-motion-graphics-templates.html)　同じ候補を名前順と別の並べ替え条件で表示し、並びが変わってもプレビューで同一物を特定する。（公開手順）
- [A327](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/customize-motion-graphics-templates.html)　作者が公開したチーム名と色を変え、元テンプレートから追加した次の配置と比較する。（公開手順）
- [A328](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/use-motion-graphics-templates-from-adobe-stock.html)　Stockの対象テンプレートを選び、プレビューで見たものと開いたテンプレートの見た目を照合する。（公開手順）
- [A361](https://helpx.adobe.com/premiere/desktop/add-text-images/insert-images-and-graphics/tips-for-authoring-motion-graphics-templates.html)　許容長を超える名前と差し替え素材を試作テンプレートに入れ、作業者が直せる設定を確かめる。（公開手順）
