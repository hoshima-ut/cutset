# GR-06 テロップとフォントの検索 — 設計

[要件](requirements.md) ・ [設計](design.md) ・ [作業・試験](tasks.md) ・ [分野一覧](../README.md)

## 操作と状態遷移

検索範囲をグラフィック・字幕・書体に分けて指定し、本文と該当時刻を一覧表示する。置換対象の行だけを選んで確定する。

## データと処理境界

結果には配置ID・レイヤーID・一致文字範囲・案件版を付ける。書体置換と文字列置換は別操作とし、既存の個別文字装飾を維持する。

## 既存実装との対応

方針は「既存部品を利用」。対象マイルストーンは[M5](../../../development/milestones.md)。

上流コードの照合先：[crates/engine/src/graphics.rs](../../../../crates/engine/src/graphics.rs)。
