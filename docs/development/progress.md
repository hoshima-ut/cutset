## 01の最初の変更

**編集者の操作**。パイロットの素材で「間を確認」を開き、固定候補A・B・Cをキーで巡回する。原音と短縮案の前後を同じ位置から再生し、AとBを採用予定に、Cを保留にする。取消すると開く前の位置とフォーカスに戻り、元の案件を手で編集し続けられる。

**変更箇所**。文字起こしパネルとセッション中の候補状態から始める。デモ用の固定候補は試験データか明示的な試用経路に限定する。空の案件・対象外の素材で候補を捏造しない。基準案件の合成音声には文字起こしがないため、01は推論モデルのダウンロードに依存しない。

**受入条件**。

- 原音と短縮案が耳で区別でき、保留した呼吸は原音の長さで聞こえる。試聴・キー巡回・取消だけではシーケンス、案件の変更状態、Undo/Redo履歴が変わらない。
- 字幕入力中のIMEが巡回キーを受け取るとき、パネルのショートカットが同じキーで発火しない。未選択・対象消失でも誤った配置を再生しない。
- セッション状態のテストに加え、パネルを実際に開いて候補切り替えと取消を行うUIテストを加える。既存の[パネル試験](../../crates/ui-egui/tests/it/transcript_ui.rs)と[フォーカス試験](../../crates/ui-egui/tests/it/ui_keyboard_focus.rs)を入口にする。リリース済み上流の一括削除のテストも引き続き通す。

```sh
cargo test --locked -p filmcraft-edit --lib pauses_are_found_and_removed_in_one_pass
cargo test --locked -p filmcraft-engine --lib transcript_tests::
cargo test --locked -p filmcraft-ui-egui --test it transcript_ui::
cargo test --locked -p filmcraft-ui-egui --test it ui_keyboard_focus::
```

追加するUIケースは上記の対象モジュールに配置する。各コマンドはリポジトリ直下で実行し、選択した試験名・実行件数・終了コードを記録する。初回の変更により失敗するケースを先に確認し、実装後に同じケースの成功を比較する。耳で聞いて「自然な間」と判断できたかは編集者が記入する。

## 02で確かめる境界

25 fpsの元位置 [205,245) と [505,565) を詰め、[800,825) は残す。確定後は1,600フレームから1,500フレーム、残した間は [700,725)。BGMの確認音は位置100のまま。古い基準版や新たにロックされた対象を渡した場合は全体が未適用となる。同じ操作の再送でさらに100フレーム短くならない。保存後は新しいプロセスで開いて確認する。[既存の字幕・リップル・Undo試験](../../crates/engine/src/ripple_delete_tests.rs)

## 再開メモ

01のうち、固定候補から試聴区間を返す読取専用CLIを実装した。次はGUI再生、キーボード巡回、取消後のフォーカス復帰を実機で確かめる。開発者はパイロットの上流手編集を再現し、01の試験名・作業ブランチ・試聴時の観察から記録を開始する。区切りごとに対象コミット、変更した経路、実行済みの検証、編集者の未確認事項、次の一手をこの欄または対応する変更のレビュー記録へ残す。

## 読み取り専用の試聴計画を試す

クローン直後は次の一行で試せる。

```sh
python3 tools/cutset_trial.py --inspect tools/fixtures/interview-layout.json --cut A B
```

実際の案件を照合する場合は、同じID・配置を持つ25 fps基準案件で次の手順を実行する。試聴窓は先頭を含み末尾を含まない元位置フレーム。出力はGUI担当への入力で、案件保存・音声再生は行わない。

```sh
./target/release/filmcraft-cli --project target/first-run/interview-64s.fcproj inspect sequence > target/first-run/sequence.json
python3 tools/cutset_trial.py --inspect target/first-run/sequence.json --cut A B
python3 tools/test_cutset_trial.py
```

AとBを選ぶと残すCは [700,725)、終端は1500。三つとも選ぶと映像終端1475、固定BGMを含むシーケンス終端1500。次のGUI試験で同じ元フレームの音を編集者が比較する。
