# AIモデルの接続と編集権限

この文書は公式AIプラグインの実装契約。最初の対象は、選択したインタビューの文字起こしからカット案を作る操作。編集者はログインなしで案件を開ける。設定の「AI接続」から接続を追加し、編集画面では接続済みのモデルを切り替える。モデル名の横に「この端末」「個人プラン」「API従量」の請求経路、送信先、入力の種類を表示する。

## 接続方法

| 接続 | 編集者の操作・請求 | Cutset側の契約 |
| --- | --- | --- |
| ローカル | インストール済みの音声モデルを選択。外部推論料なし | 音声認識・発話区間検出は既存speechを再利用。モデル取得の通信、サイズ、ライセンスは別途明示する。[既存実装](../../crates/speech/README.md) |
| APIキー持ち込み（BYOK） | 設定でプロバイダーを選び、本人または組織のAPIキーを登録。モデル利用分はそのAPI契約へ | 公式の接続先にデスクトップから直接接続。最初はOpenAIまたはAnthropicのテキスト提案を対象にする。機能ごとに入力形式、ツール対応と利用可能モデルを取得。Cursorのモデル設定・VS Codeの能力フィルターを参考にする。[Cursor](https://cursor.com/help/models-and-usage/api-keys) · [VS Code](https://code.visualstudio.com/docs/agent-customization/language-models) |
| ChatGPT個人プラン | 対象Plus/Pro利用者がシステムブラウザで「Continue with ChatGPT」を選び、プラン利用に個別同意 | OSS・ローカルホスト向けの公式Sign in with ChatGPTを使用。登録・アカウント・workspace・ホストを区別し、PKCE/state/nonceと権限を検証。対象のResponses APIに限り、文字起こしテキストや対応静止画を送る。公開Webサービス版・有料配信への適用は提供条件を再確認する。[概要](https://developers.openai.com/siwc/token-sharing-open-source) · [登録](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) · [入力・ツール制限](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations) |
| Claude個人プラン | 本人が公式Claude Codeにログインし、Cutsetの編集ツールをMCPで呼ぶ構成 | Claude Pro/Maxのログイン・セッションは公式クライアントが管理。Cutset内の直接推論はAnthropic APIキー等の認められた経路を使う。外部エージェントには下記の制限付きツールを公開する。[Anthropicの条件](https://code.claude.com/docs/en/legal-and-compliance) |
| GitHub Copilot個人プラン | 対象の利用者が公式GitHub認可で接続する拡張候補 | Copilot SDKのユーザー認証をプロバイダーアダプターとして評価。利用条件、組織ポリシー、利用量とSDKバージョンを確認して公開。Git操作の資格情報を自動流用しない。[SDK認証](https://docs.github.com/en/copilot/how-tos/copilot-sdk/auth/authenticate) |

公式仕様の確認日は2026-11-26。個人プランの提供範囲、対応モデル、上限は接続ごとに変わる。モデル選択・資格情報保管・サブスク統合は実装予定。上流からは文字起こし、編集コマンド、CLI/MCPの検査・編集を引き継ぐ。[上流MCP](../reference/filmcraft/agents.md)

## 編集者から見た一往復

1. タイムラインで区間を選び「カット案」を開く。送る文字範囲・フレーム数・送信先を確認する。発話の解析はローカルで完了できる。クラウドへ映像全体や音声を添付する場合は、対応経路と追加同意が必要。
2. 「この端末」「自分のAPI」「接続したプラン」から選ぶ。失効や上限超過時は提案を保留し、再接続またはモデル変更を自分で選ぶ。料金不明は「提供元で確認」、追加料金が発生する経路への切り替えには明示選択を求める。
3. 返答は候補カードにする。根拠の字幕と時間を読み、原音と短縮案を試聴して採否を決める。編集中の文字入力を保ったまま中止できる。採用した候補を一度で確定し、一度のUndoで戻す。

## ホストとプラグインの責務

| 境界 | 入出力と失敗時の挙動 |
| --- | --- |
| 接続設定と資格情報 | 設定には接続ID・モデル・請求種別、秘密値はOSの資格情報ストア。プラグイン・案件・Git・クラッシュ報告・ブラウザのlocalStorageに鍵を渡さない。接続解除はローカル資格情報を削除し、提供元の失効経路を案内。ホスト利用不能時は保存を止める。 |
| モデルアダプター | 対応能力一覧、提案ストリーム、中止、失効・制限エラーを共通化。音声、映像、画像、テキストの能力を区別。ChatGPTプランの現行previewは音声/動画入力・文字起こしAPIが対象外。リクエストごとに必要最小限の文脈を組み立てる。 |
| 編集ホスト | エンジンの安定ID、元区間、基準版を渡す。モデル出力は候補データとして型・区間・対象・重複を検証。編集ホストだけがユーザー確定後にロック・基準版を再確認し、単一Undo単位で適用する。読み取った字幕・素材メタデータは命令として実行しない。 |
| 外部エージェント | 新設の制限付きMCP入口は対象案件の読取・提案のみを初期許可。既存の汎用MCPにはファイル操作や編集命令があるので、そのまま公式AIの権限境界にしない。ユーザー操作、AIプラグイン、外部エージェントで同じ候補と試聴結果が出る。 |
| 将来のブラウザ | 能力を起動時に判定する。ローカルのデスクトップ接続を共有する際は明示ペアリングと短命セッションを使用。Web配布・資格情報管理の要件が揃うまでは読み取りレビューを先行する。 |

## リリース受け入れ

- ネットワークを遮断して案件を開き、手編集・保存・ローカル解析が続く。APIキー未登録の初回起動で外部推論リクエストが0件。
- 偽プロバイダーで、選択した字幕だけが送られることを記録。失効・429・キャンセル・ストリーム切断・応答形式不正・モデル消失を再現し、編集中の案件、課金経路、Undo履歴を維持する。
- テスト用識別値を資格情報に入れて保存・ログ・書き出し・クラッシュレポート・プロンプトを点検。編集者が鍵を削除すると再利用できない。
- 古い版、ロック対象、二重送信、範囲外を含む候補を拒否し、途中適用を残さない。キーボードと読み上げで送信内容・請求先・採用差分が確認できる。
- 実サービスの試験は参加者の明示操作で行い、接続種別、確認日、成功した入力種別だけを記録する。料金・権限・品質をモック試験から推定しない。
