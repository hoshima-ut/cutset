## 最初の15分

1. Git、Python 3、Gitleaksを用意し、リポジトリ直下で `tools/install-hooks` を実行する。作業コピーを新設したときも行う。
2. `python3 tools/check_handbook.py` と `tools/secret-guard staged` を実行する。Rustの開発環境を準備したら `cargo test --locked -p filmcraft-time` で時間計算を確認する。初回のビルドは環境によって時間がかかる。
3. 作業台01の受入条件を読み、既存の無音検出と文字起こしパネルから対象コードをたどる。編集者の試聴が必要なケースには担当を付ける。再開時は同じ作業台を更新する。

## 文書の置き場所

[spec/](../spec/README.md) に製品仕様と受入条件、`handbook/` に開発の判断・手順・引継ぎを置く。コードと同じブランチに置くので、仕様変更・実装・受入を一つの差分で読める。既存の `docs/` はFilmCraft由来の技術資料で、エンジン、コマンド、形式、上流ADRの説明と参照先を保つ。上流を更新したときは関連するCutsetの判断との違いを確認する。[上流の構成](../docs/architecture.md) · [CLI・MCPの仕様](../docs/agents.md)

READMEは利用者の入口、AGENTS.mdは開発エージェントの入口、SECURITY.mdは報告窓口。社内案件の素材・未公開仕様・利用者別の評価記録は管理者が許可した私有の保管先を使う。公開する再現手順には合成素材と必要最小限の結果を書く。
