# 操作面と自動化の受入条件

カタログの各項目は同じカテゴリの下記条件を継承する。GUIからは編集者が意図した結果を視聴でき、支援技術からは作用先を判別でき、自動化クライアントからは同じ結果を検査できることを確認する。表にある命令名や応答は設計上の役割を示す。既存の名前と機能の対応は [FilmCraftのコマンド一覧](../native-commands.tsv) で調べる。

| 領域 | UIと編集体験 | アクセシビリティ | AI・CLI・外部ツールからの観測 |
| --- | --- | --- | --- |
| workspace | 素材側と完成側の再生位置を同時に表示し、パネルを戻したら直前の選択を復元する。 | パネル、フォーカス、選択、全画面の状態を読み上げ、キーボードで元のパネルに戻れる。 | パネルとモニターを別IDで列挙し、フォーカス・範囲と現在時刻を読める。 |
| media-delivery | 原本、代理、オフラインを識別し、取り込みや納品の対象・版・保存先を確定前に表示する。 | 素材の状態とキューの進捗・失敗理由を文字で取得できる。進捗を読むたびにフォーカスが飛ばない。 | 媒体と配置のID、入力・出力能力、ジョブIDと終端状態、警告を返す。依頼のやり直しで同じ納品を重ねない。 |
| editing | トリム前に動く範囲を示し、前後を試聴してから確定できる。取消は試行前の位置へ戻る。 | 端・方向・フレーム差・対象行を音声とテキストで確認し、ドラッグなしで調整する。 | 基準版、対象IDと時間単位を要求し、移動・変更した配置と新しい尺を返す。ロック済みの対象を明示する。 |
| effects | ハンドルと数値を同期させ、処理前後を同じフレームで比較する。 | 画面上のハンドルと等価な座標入力、レイヤー名、選択中のキーの時刻・値を提供する。 | パラメーターの範囲・単位・時刻、入力レイヤー、バイパス状態と未対応の実行経路を取得できる。 |
| color | 素材・作業・表示・納品変換を別々に表示し、参照ショットとスコープを固定できる。 | 色だけに依存せず各チャンネル名・値・基準を表示し、キーでパラメーターを戻せる。 | 適用順、色空間、変換と計測対象のフレームを返し、比較前後の設定を復元できる。 |
| graphics | 本文編集とレイヤー選択を分け、元の場所で日本語の変換を完了できる。 | 入力中のショートカットを抑止し、読み上げ可能なレイヤー順とフォント不足理由を示す。 | 本文・範囲・書体・参照スタイル・上書きを分けて返し、複数配置を参照する変更には対象数を提示する。 |
| captions | 波形、本文、字幕区間を同期する。文字訂正だけなら音と画の位置が変わらない。 | タイムラインを使わず一覧から開始・終了・本文を直し、重なりを時間と本文で把握できる。 | 字幕ID、言語、開始・終了、本文を取得し、訂正と映像編集で異なる命令を指定する。 |
| audio | まず問題のチャンネルを特定し、ミュート・ソロ・補正前後を聴き比べられる。 | メーターの数値、単位、ピーク状態、経路を文字で提供し、急速な読み上げの反復を避ける。 | チャンネル割当と接続先を列挙し、サンプル区間、測定窓、実際の出力を明示する。 |
| commands | メニュー、コンテキスト操作、検索を同じ対象とコマンドに解決する。無効であれば必要な選択を示す。 | キーだけで検索・起動・取消し、実行後に元の作業対象へフォーカスを戻す。 | 有効なコンテキストと引数を列挙し、GUIで無効な対象へ要求した場合も同じ理由を返す。 |
| workflow | 複数テイクと編集案を同じ位置で試聴し、採用後も原本の範囲・注記・別案へ戻れる。 | 各候補に識別可能な名前を付け、キーボードで前後の音と選択結果を確認する。 | 採否、採用元の版・配置、原本への範囲対応、受け渡しで落ちる属性を検査できる。 |
| ai-plugin | 依頼の対象、外部に送る媒体、変更差分と費用負担先を実行前に確認する。個別採否と一括Undoを提供する。 | 差分を文字の一覧でも提示し、読み上げ、キーでの個別除外、保留、取消を可能にする。 | 能力一覧と権限を交渉し、対象・基準版・要求IDを渡す。失効や競合が起きたら型付き結果を返し、永続化するデータから秘密値を除く。 |
| browser | 未保存、ローカル保存、同期済みを区別し、通信が戻ったときに古い操作を勝手に適用しない。 | 通信変化や同期競合を告知し、オフライン中もキーで候補を確認・保存できる。 | ホスト能力、キャッシュと永続版を分け、同じ操作列をネイティブ・Wasmで再生して比較できる。 |

## 編集時間の基準

素材上の範囲と配置上の範囲を半開区間で記述する。例えば25fpsの50フレームを20フレーム地点で分割すると、双方の尺は20と30で境界フレームを重複させない。音声はサンプル単位、映像はフレーム境界で評価する。タイムコードは表示であり、29.97ドロップフレームで番号を飛ばす地点にも実フレームが存在する。ブラウザでの再生速度やUIの丸めから保存値を逆算しない。

## 最初の編集者試験

同じ案件で「発言を探す、試聴する、原音を残して映像を詰める、字幕の固有名詞を直す、保存・再開して納品する」を手操作・キーボードのみ・AI併用で行う。参加者の経験、成功段階、介助の有無、意図外変更、Undo回数、初稿確定までの時間、再生落ち・音ずれ・スクラブ応答を記録する。能力差を隠さず、公開する結果には端末、素材条件、ビルドと検査方法を添える。合否基準を増やす判断は測定後に記録する。[具体的な初期状態と期待値](journeys.json)
